# 魔方 · 打乱与逐步还原（Rubik Guide）

一个零依赖、单页的三阶魔方教学工具：打乱后依据当前状态生成还原步骤，逐步演示「转哪一面、朝哪个方向」，3D 立方体与六面展开平面图双向联动高亮。纯原生 HTML + SVG + JavaScript，无 Three.js、无构建、无外部资源请求，直接打开 `index.html` 即可运行。

## 功能

- **打乱魔方**：随机 20 步（同面不连续重复），逐帧动画演示，3D 与平面图同步更新。
- **生成还原步骤**：对打乱序列求逆并化简（同面合并、消去 360°），得到最短执行序列；每步显示标准记号（`R` / `R'` / `R2`）与中文说明（如「右面 · 顺时针」）。
- **逐步执行**：前进一步 / 退回上一步（均带 90°/180° 转动动画），点击立方体也可走一步；点击步骤列表任意一行可**前跳或倒退回溯**到该步（中间步快速掠过，末步正常速度收尾）。
- **3D ↔ 平面图联动**：拖动旋转视角（轨道相机 + 透视投影 + 画家算法排序）；悬停/点击展开图任一面或格子，3D 贴纸同步发光，反之亦然；当前步骤要转的那一层在两侧同时用金色描边高亮，并叠加旋转方向弧线箭头（顺 / 逆 / 180°）。
- **背面提示**：当前步骤的面若朝向背面，面板会给出「该面在背面」提醒。
- **完成检测与进度**：进度条、步骤计数、复原判定（54 贴纸全部归位）。
- 移动端自适应（面板置顶、立方体缩放）。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 可运行的单文件应用：内联了魔方模型、3D 投影渲染、展开图、动画与全部 UI 逻辑 |
| `engine.js` | 魔方引擎（纯逻辑、无 DOM）：`Cube` 类、面/颜色定义、矩阵工具，UMD 风格导出，浏览器与 Node 测试共用 |
| `inspect.js` | 调试/测试工具：把 `Cube` 状态导出为每面 3×3 颜色网格（从外部看的行列约定），便于断言与肉眼检查 |

## 技术要点

- **立方体模型**：26 个 cubie，各自记录整数位置 `pos ∈ {-1,0,1}³` 与 3×3 整数朝向矩阵 `rot`；面转 = 对该层 cubie 的 `pos` 施加旋转矩阵、`rot` 左乘同一矩阵，贴纸朝向随方块刚体旋转，无需维护 54 个贴纸索引。
- **90° 取整 / 动画浮点分离**：状态转动的旋转矩阵取整保证坐标精确；转动动画的中间帧使用不取整的浮点矩阵（否则 45° 会被舍入成缩放+剪切导致贴纸变形）。
- **自研光栅**：透视投影（相机方向 / 右向 / 上向基底 + 透视因子）、法线点积剔除背面、按平均深度排序的画家算法、方向光着色（`shade × hexMul`）。
- **还原策略**：`simplify(invert(scramble))` —— 对打乱序列做逆序取逆，再合并相邻同面转动；保证与打乱严格互逆，可复原。
- **测试钩子**：页面暴露 `window.cubeApp`（`scrambleForTest` / `solveForTest` / `stepForTest` / `solved` 等），可驱动无头测试走真实的打乱→生成→逐步执行路径。

## 本地运行

无需安装任何依赖，任选其一：

```bash
# 直接打开
open index.html          # macOS
python3 -m http.server 8000   # 或起一个静态服务后访问 http://127.0.0.1:8000
```
