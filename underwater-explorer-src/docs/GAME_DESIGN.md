# GAME_DESIGN — 游戏设计（摘要）

原创横向侧视海底探索游戏。仅参考《潜水员戴夫》的海底探索/捕鱼玩法结构，不使用其任何原始素材。

## 1. 核心循环

```
母船 → 下潜 → 探索海底 → 发现鱼群 → 鱼叉捕鱼 → 躲避/对抗危险生物
→ 进入洞穴 → 探索沉船 → 开启宝箱 → 管理氧气和负重 → 返回母船 → 探索结算
```

明确**不做**：餐厅、厨师、寿司、顾客、菜谱、服务员、店铺经营。

## 2. 玩家

- 潜水员：横向移动 + 上下游动，WASD / 方向键。
- 运动模型：加速度 + 阻尼 + 最大速度（水下惯性），禁止瞬移。
- 状态：待机 / 游泳 / 转向 / 受伤 / 鱼叉射击 / 昏迷。
- 资源：HP、氧气 O2、深度 Depth、负重 Weight。

## 3. 鱼（50 种目标）

- 数据驱动：`src/data/fish.ts|json`；字段 id/name/category/sprite/hp/speed/weight/value/depthMin/depthMax/behavior/aggressive/rarity。
- 目录：common / uncommon / rare / deep / aggressive / boss。
- 行为模板（复用，非一鱼一套）：普通巡游、群游、遇玩家逃跑、快速逃跑、慢速漂游、伏击、主动攻击、深海游荡、大型鱼、Boss。
- 构成建议：20 普通 / 10 群游 / 8 稀有 / 5 深海 / 5 危险 / 2 大型。

## 4. 危险生物

第一版：鲨鱼（状态机 PATROL→DETECT→CHASE→ATTACK→COOLDOWN→RETURN，攻击有前摇/冲刺/命中范围/冷却）。
后期：剑鱼、鮟鱇鱼、大型鱿鱼（复用 EnemyStateMachine / DamageSystem / MovementSystem）。

## 5. 世界

- 深度分层：0–30 浅海 / 30–80 珊瑚区 / 80–130 中深层 / 130–200 深海 / 200+ 黑暗区；随深度改变海水颜色、光照、鱼种、环境音、危险度。
- 区域：普通海域、珊瑚区、海草区、洞穴、深海洞穴、沉船（Hull/Cabin/Cargo/TreasurePoint）、宝箱区域。
- 洞穴为配置数据 CaveArea[]：入口窄、内部暗、稀有鱼多、宝箱概率高。

## 6. 系统

- 鱼叉：鼠标瞄准 + 左键发射；HarpoonSystem / HarpoonProjectile / CollisionSystem。第一版仅普通鱼叉。
- 背包：捕获入包，记录鱼种/数量/重量/价值；负重 UI `14.2kg / 30kg`；<80% 正常，80–100% 轻微减速，≥100% 明显减速（不锁死移动）。
- 氧气：持续消耗；<25% 报警；耗尽持续扣 HP（不立即失败）。
- 宝箱：Common/Rare/Epic；状态 CLOSED/OPENING/OPENED；掉落金币/氧气补给/稀有收集物。
- 返航：回到水面区域 → 确认 → 结算（捕获/数量/总重/总值/稀有物/最深深度）。
- 奖励分层：普通/稀有/史诗（生成率、速度、深度、价值差异化），无抽卡。
- 存档：localStorage（设置、最高深度、图鉴、累计捕获、已发现鱼种），无服务器。

## 7. UI

HP、O2、深度、负重、背包、鱼叉状态、鱼名/价值、拾取/宝箱提示、暂停、探索结算、鱼类图鉴。要求不遮挡主画面、适配 16:9、窗口缩放正常。

## 8. 音频

- 环境：海水、气泡、水流、深海低频。
- 行为：游泳、鱼叉发射/命中、捕鱼成功、受伤、鲨鱼攻击、宝箱开启、拾取、低氧报警、UI 点击。
- BGM：浅海探索 / 深海探索 / 危险区域 / Boss；渐入渐出、区域切换、循环。
- 混音：总音量 / BGM 音量 / SFX 音量三通道。

## 9. 视觉

浅海蓝→深海暗蓝纵向渐变、光束、fog、气泡、漂浮尘埃、轻微屏幕水感；远景/中景/实体/前景多层视差；海草摆动。性能优先：InstancedMesh、Sprite 复用、对象池、距离裁剪。目标 1080p 桌面 60FPS。
