# Asset Plan

原则：第一版全部使用**程序化占位资产**（简化几何 + Toon 材质 + 描边），
绝不因缺少正式模型而停止开发。始终保持 `Visual Mesh ≠ Collider`。

## 占位资产（当前）

| 资产 | 当前实现 | 阶段 |
| --- | --- | --- |
| 地面 | GridHelper 网格 | Phase 0 |
| 测试立方体 | Box + MeshToonMaterial | Phase 0 |
| 坐标柱 | Cylinder + MeshToonMaterial | Phase 0 |

## 碰撞体规范

- 每个视觉资产配套一个简单碰撞体（球 / 圆柱 / 盒），参数写在资产定义中。
- 船体：球形或胶囊近似；边界浮标：圆柱；岛屿：圆柱 / 球。

## 红线

- 不使用任何第三方版权模型、贴图、字体、音频。
- 所有素材程序生成或原创手绘。
