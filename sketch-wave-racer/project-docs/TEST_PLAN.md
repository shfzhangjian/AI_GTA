## Phase 0 — 项目初始化与文档系统

### 前置条件

- macOS / Windows / Linux，已安装 Node.js 18+（本机为 v22）
- 现代浏览器（Chrome / Edge / Safari / Firefox）

### 测试步骤

1. 终端进入项目目录：
   ```bash
   cd sketch-wave-racer
   ```
2. 安装依赖（若未安装）：
   ```bash
   npm install
   ```
3. 启动开发服务器：
   ```bash
   npm run dev
   ```
4. 按终端显示的地址打开页面（预期 `http://localhost:5173/` 或类似）。
5. 观察页面：应看到浅米色背景上的 3D 场景 —— 一个地面网格、一个黄色占位立方体在缓慢旋转、一根红色坐标指示柱，左上角有 HUD 文本（标题 + FPS）。
6. 按 F12 打开控制台，确认无红色报错。
7. 调整浏览器窗口大小，画面应自适应不变形。
8. 验证构建：
   ```bash
   npm run build
   npm run preview
   ```
   打开 preview 地址，画面与 dev 一致。

### 预期结果

- 页面正常渲染 3D 场景，立方体持续旋转，FPS 稳定（≥ 30）。
- 无控制台错误。
- build 成功生成 `dist/`；preview 可正常打开。

## Phase 1 — 基础水面场景与玩家载具控制

### 测试步骤

1. dev 服务器应仍在运行；直接刷新（或打开）**http://localhost:5173/**
2. 观察开场画面：蓝色动态海面在起伏（有亮带移动、远处波峰泛白）、渐变天空与
   太阳、地平线上有一圈绿色小岛的剪影、周围散布红绿浮标在随波起伏
3. 按 **W**：船加速，能看到船头微微抬起、随波浪上下浮动；底部速度条增长，
   左上角 FPS 旁显示 km/h
4. 速度起来后按 **A / D**：船转弯并明显"甩"出侧向滑行（船身向内侧倾），
   松舵后回正——这就是滑行感
5. 按 **S**：先刹车再倒船；水中松油门会缓慢滑停（比陆地慢很多）
6. 摄像机应平滑跟在船后，速度越快拉得越远越高，无抖动
7. 控制台只有一条绿色启动日志，无红色报错
8. 自动测试：终端运行 `npm test`（6 项断言）与 `npm run build`

### 预期结果

- 水面全程有起伏和移动高光，绝不是纯蓝平面
- 驾驶有明确的水上滑行与惯性，不会像陆地卡丁车
- 无报错；build 与 npm test 全绿

### 已知限制（预期内）

- 船与浮标/岛屿**不会发生碰撞**（Phase 3 实现），可以径直穿过
- 没有赛道与圈数（Phase 2），目前是自由水域

## Phase 2 — 赛道、边界、检查点与圈数

### 测试步骤

1. 硬刷新 **http://localhost:5173/**
2. 开场应看到：一条浅色航道从起点出发、两侧红绿浮标链、前方黑白格起终点门；
   环中央有一座椰子树地标大岛；右上角有 P1 / Lap 1/3 / Time 面板
3. 按 **W** 沿航道跑：经过黄色拱门时 Time 在走；**冲过起点格纹线后 Lap 变 2/3**，
   上方闪出绿色"第 2/3 圈 ✓ 圈速"条
4. 连续跑 3 圈：Lap 3/3 后再过一次线应闪 **🏁 完赛条**
5. **越界测试**：故意冲出浮标链——速度骤降、红字警告"偏离航道"闪烁；不回赛道
   3.5 秒后船自动回到最近检查点
6. **R 键**：任意时刻按下立即回到最近检查点（速度清零）
7. 反向开：倒着穿过起点线不应计圈
8. S 弯处有交错木桩，现在可以穿过（下阶段才碰撞）
9. `npm test`（13 项）与 `npm run test:e2e`（自动绕圈完赛 + 真实按键）全绿；`npm run build`

### 预期结果

- 圈数只按正确方向、正确顺序计；HUD 数字与截图证据一致
- 越界有明确减速 + 警告 + 自动重置三段式反馈
- 排名面板始终 P1（单人），无报错

## Phase 6 — 真实感水面优化（本轮新增）

### 测试步骤

1. 硬刷新 **http://localhost:5173/**，把镜头贴近水面观察：
   近景水面应有**细碎碎波闪动**（双层波纹法线），太阳反光带随碎波跳动；
   侧面看水面应映出天空色（菲涅耳+环境双段），大浪坡面挂**蠕动的白泡沫**
2. 开船沿航道跑：船尾连续喷白水花；按住 Shift 急弯时外侧甩出更多溅水
3. 全速冲 t≈0.30 跳台：落水瞬间**环形水花炸开**（速度越大花越多越大）
4. 画质对比：控制台执行 `localStorage.setItem('swr-quality','low')` 硬刷新 →
   水面网格明显变平、粒子变少、无碎波闪动；再 `localStorage.removeItem('swr-quality')`
   回默认 high
5. 性能观察：左上 FPS；low 档在软渲染机器上应明显更流畅
6. `npm test`（43 项）与 `npm run build`

### 预期结果

- 水面观感比 Phase 1-5 有质变：碎波光、反射感、泡沫、粒子尾迹、水花
- 画质分档即时生效（localStorage），默认 high
- 粒子不影响任何判定（碰撞/圈数照常），无控制台报错

## Phase 7 — UI、语言、本地记录、打磨（本轮新增）

### 测试步骤

1. 刷新 **http://localhost:5173/**：应看到**开始菜单**（标题、赛道、控制说明、
   最佳记录、语言/画质按钮）——菜单开着时世界静止（判定冻结）
2. 点 **开始比赛**：菜单收起 → 3·2·1·GO → 开跑；左下角出现**小地图**
   （航道折线 + 你的黄点 + AI 彩点实时移动）
3. 按 **Esc**：暂停菜单（含"继续"按钮）；再 Esc 或点继续恢复
4. 跑完 3 圈：弹**结算界面**——你的名次大字 + 全员名次表（颜色点+用时+圈速）+
   首次成绩有 **★ 新纪录**；点 **再来一局** 直接重开（出生格+倒计时）
5. **本地记录**：完赛一场后退出页面再进 → 开始菜单"最佳记录"显示最快圈速/
   完赛时间/名次；跑一场更差的不会覆盖
6. **语言**：菜单点"语言: 中文 ▸ English"→ 全站文案即时切英文（菜单/HUD/结算/
   道具名）；刷新后仍是英文（localStorage 记住）；改回中文
7. **画质**：菜单点"画质"按钮 high→auto→low 循环：水面网格/碎波/粒子明显
   变化即时生效；刷新保持所选档
8. **起步规则（转速版）**：点开始比赛进倒计时后——
   a. 按住油门不放：转速针狂升、马达膨胀 + 引擎低吼，但**船不动**；GO 瞬间
      "轰隆"爆缸 + 黑烟火水花 + 便利贴"抢跑！发动机爆缸了！"，随后约
      1~1.5s 熄火（油门无效），恢复后才能正常行驶；
   b. 按住后在转速表**绿区（约 27~48km/h 刻度）内松手**：GO 瞬间"完美起步"
      弹射（便利贴"完美起步！"+ 扫频音 + 明显初速）；轰得越满弹射越猛；
   c. 只轻点一下油门就松（转速掉回 0）或全程不按：GO 帧干净起步，不奖不罚；
   d. START 之前就在菜单上按住 W：转速不动、不背抢跑锅；
   e. 观察 AI：约三成会自己轰到爆缸（黑烟），约三成卡绿区弹射。
9. `npm test`（**59 项**全绿：7 phase + start_rules 10 项）与 `npm run build`
   （build 本机受 rollup 签名阻塞，见 KNOWN_ISSUES H）

### 预期结果

- 比赛流程完整：菜单 → 倒计时 → 比赛 → 暂停可用 → 结算 → 重开
- 最佳成绩/语言/画质跨会话持久
- 无控制台报错；菜单打开期间判定完全冻结（不会暂停偷跑圈数）
