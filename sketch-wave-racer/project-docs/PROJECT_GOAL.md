# Sketch Wave Racer — Project Goal

**Sketch Wave Racer** 是一款第三人称 3D 水上竞速游戏（浏览器端）。
核心玩法参考经典"卡丁车竞速 + 道具对抗"机制，但所有角色、赛道、UI、音乐、资产均为原创，不复制任何现有知名游戏内容。

## 一句话目标

做一个"水上卡丁车竞速"感觉的游戏：卡通简笔画世界里，跑一张高品质真实感水面的竞速赛道。

## 核心玩法

- 玩家驾驶小型竞速船 / 水上摩托
- 多名 AI 选手同场比赛
- 比赛按圈数结算
- 加速、转向、漂移、跳跃台、道具拾取、道具攻击、防御
- 排名系统、完成名次与计时系统
- 开始倒计时与结算页面

## 视觉风格

- 场景 / 角色 / UI：简笔画、手绘卡通、清晰轮廓线、明快配色、低复杂度模型
- 水面：明显优于普通卡通平面水面 —— 动态波浪、实时高光、菲涅耳边缘反射、
  法线扰动、船尾水花、尾迹、泡沫、风感流动
- 最终对比感："卡通世界中的高品质真实水面"

## 体验目标

- 操作直观；水上滑行感明显；弯道漂移有乐趣；道具系统增加对抗性

## 技术要求

- Vite + JavaScript ES Modules + Three.js（HTML/CSS）
- 可选：Cannon-es / Rapier（物理）、postprocessing（轻量后期）
- `npm install` 可安装；`npm run dev` 可启动；`npm run build` 可构建
- 纯本地浏览器运行，不依赖自建服务器后端

## 语言

- 中文 / English，统一 i18n 管理，浏览器语言自动选择，手动切换存 localStorage

## 明确禁止

1. 复制知名竞速游戏的角色、名称、赛道、UI、音乐、资产
2. 使用侵权素材
3. 因缺少正式模型而停止开发（用程序化占位模型）
4. 所有代码堆进一个文件
5. 未运行就声称"已测试通过"；build 失败就宣布完成
6. 未经用户确认自动进入下一阶段
7. 水面只是纯蓝色平面
8. 只写方案不落代码；虚构启动地址或测试结果
