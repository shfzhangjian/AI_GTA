# 遗物猎场 / RELIC FIELD

一个以「把旧世界的故事带回家」为主题的等距动作寻宝肉鸽游戏。玩家主动攻击、瞄准、闪避和施放技能，在随机守卫与装备选择中形成自己的组合。装备的发现记录跨远征保留，角色等级与遗物组合每次重置。

## 核心体验

动作由玩家决定：近战判断距离与角度，远程判断弹道与穿透，闪避用于穿过攻击预警。收集推动探索：金色秘匣提供新武器、补给和遗迹碎片，战斗掉落经验与金币，图鉴记录每一次真实获得的发现。肉鸽提供变化：每次的随机种子改变敌人构成、出场位置、宝箱位置与奖励选择。

场景的结构固定，三个区域使用不同地砖、色彩与领主。当前原型没有随机分支地图；它让核心操作、八类武器行为和六系遗物组合先完整运行。

## 一局流程

1. 在营地选择 10 名猎人之一，再选择任意起始武器。24 把武器均可试用，收藏标记在实际出征、拾取之后写入。
2. 进入遗迹。普通房间有两波守卫；每个区域的第 3 房间是领主战。
3. 主动搜索秘匣。靠近按 F 开启，从 3 把武器中选择替换，或保留当前武器；同时获得随机补给、金币和碎片。铜铃有 4 项武器选择。
4. 捡起掉落，获得经验。升级获得生命和少量基础伤害提升，再选择一件遗物。
5. 净化房间，恢复 12 生命，获得一件遗物与 12 枚碎片。拿走房间秘匣后按 F 前进。
6. 完成 9 个房间、击败 3 位领主后归档全部碎片。途中倒下或撤退归档 40%，收藏记录全部保留。

远征存档只保存银行碎片、发现的角色 / 武器 / 遗物 / 补给、出发次数、最高深入房间和通关次数。本局进度不支持中断续玩。碎片当前是收藏成绩，营地消费是后续功能。

## 动作规则

| 操作 | 行为 |
| --- | --- |
| WASD / 方向键 | 按屏幕方向移动，转换到等距地图坐标 |
| 鼠标移动 | 瞄准与八方向角色朝向 |
| 按住鼠标左键 | 按武器间隔重复攻击 |
| 空格 | 0.20 秒冲刺、0.30 秒无敌，基础冷却 1.5 秒 |
| E | 角色专属主动技能 |
| Q | 使用当前选中补给 |
| F | 开启附近宝箱，或在清场后领取秘匣 / 前进 |
| Esc | 暂停、继续或关闭普通弹窗 |
| 1 / 2 / 3 / 4 | 在奖励选择时快速选取对应项 |

手机提供方向按钮与攻击按钮，攻击自动瞄准最近的守卫；底部仍可点按闪避、技能和补给。

近战使用扇形、环形或狭长穿刺碰撞。投射物使用扫掠碰撞，避免高速弹丸穿过敌人。敌人出招有红色预警；受击有短暂免伤，重击附带短暂顿帧与震屏。伤害、掉落、状态与提示在同一套战斗逻辑中处理。

## 六种可形成的组合

| 组合 | 角色 / 武器 | 优先遗物 | 核心收益 |
| --- | --- | --- | --- |
| 火场清扫 | 烬灯 + 熔炉之心 | 不熄火种、燎原余页、焦黑灯芯 | 持续燃烧与击杀爆炸 |
| 冻时周转 | 霜书 + 冻时之书 | 寒潮怀表、永冬王冠、雪线罗盘 | 减速冻结，快速重复技能 |
| 雷链射手 | 铜铃 + 铜羽连铳 | 风暴瓶、暴雨种子、天穹碎片 | 高频投射物与多目标闪电 |
| 菌蚀续航 | 孢芽 + 蕈牙 | 活菌标本、再生琥珀、寄生芽 | 快速叠加中毒并恢复生命 |
| 回响暴击 | 鸦影 + 鸦羽双匕 | 双面铜镜、回声指骨、第二颗心 | 暴击与复制攻击、技能爆发 |
| 壁垒重击 | 铁誓 + 钟塔重锤 | 城墙铆钉、旧王印玺、逆鳞甲片 | 生命、护盾、减伤与反击 |

同系列遗物 3 件 / 6 件触发组合效果。武器元素决定每次命中的燃烧、中毒、减速或雷链，不计入遗物件数。混搭也可以成立：例如钢铁护盾保护低生命术士，菌蚀吸血延长近战生存。

## 敌人与区域

普通守卫包括近身石苔兵、远程哨兵、重装遗骸、快速跳蛛和三连弹幽灵。它们分别要求距离管理、侧向走位、寻找重击空隙、快速转火和闪避弹道。每一层提高生命与伤害，随机出场但避开玩家附近。

| 区域 | 美术气氛 | 领主 | 交替招式 |
| --- | --- | --- | --- |
| 沉没庭院 | 苔石、破拱、旧树与柔和尘光 | 苔冠守卫 | 范围震地、慢速环形弹幕、冲锋与召唤石苔兵 |
| 失火铸坊 | 暖灰砖、铜色遗械与余火 | 熔炉巨像 | 留下火场的震地、更快弹幕、冲锋与重装支援 |
| 无声书库 | 冷灰砖、回响纹样与淡紫遗痕 | 无名馆长 | 震地、密集弹幕、瞬移冲锋后交叉弹道与幽灵支援 |

地图保留宽阔走位区域，柱子形成少量阻挡。大型装饰安排在地图边缘，落地角色与敌人按地面深度排序，武器独立绘制。宝箱和出口使用暖金与浅绿，红色专用于敌人攻击预警。

## 已实现与扩展边界

已实现：完整 9 房间远征、3 领主、10 角色主动技能与天赋、24 武器攻击模式、40 遗物数值与六系组合、8 补给、图鉴筛选搜索、本地归档、触屏按钮、八方向像素动画、暂停与结算。

后续制作建议：分支房间、商人交易、碎片营地建设、独立遗物故事、更多 Boss 招式、手工动画修整、手柄支持与局内存档。需要以实际试玩反馈重新校准掉落权重、散射武器的总伤害和高层数续航，当前数值属于可玩的原型值。
