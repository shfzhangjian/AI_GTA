# 遗物猎场 · 视觉约定

色彩：深苔绿 #172723 是营地和场景底色，暖纸色 #e7e3d4 用于猎人手册，嫩苔色 #bdc995 表示生命和探索，陶土橙 #d98d70 表示敌人攻击与受伤。六系列在道具上使用独立颜色，品质辅以文字。

字体：中文标题用本地宋体 / Songti 的书页气质，正文使用本地微软雅黑 / PingFang，坐标与数值使用等宽或 Georgia。没有外部字体或 CDN 依赖。

布局：90px 顶部营地导航，左侧探索记录、中央等距遗迹、右侧纸质手册，底部固定操作和生命。小屏隐藏探索记录，角色准备移到场景下方；远征时保留全屏场景与触屏操作。

组件：直角细线条、固定网格角色肖像、几何道具图标、书页式图鉴，主操作为深绿长按钮。动画用于方向、行走、命中、掉落吸附与武器效果，装饰动画保持轻微。
