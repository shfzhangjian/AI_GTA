# 纸上归零 / Paper Zero

独立原创的静态 Canvas 2D 浏览器游戏。暖色书桌上的方格纸竞技场里，玩家操控火柴人，用四种运算符处理会走路的数字。

## 运行

直接打开 `dist/index.html`；或在项目根目录运行 `npm run build` 后用任意静态服务器打开 `dist/`。所有引用均使用相对路径，适合部署到 GitHub Pages 的子目录。

## 操作

- WASD：移动；鼠标：瞄准与射击；空格：冲刺；1–4：−1、÷2、√、mod 3；P/Esc：暂停。
- 移动端：拖动以瞄准、点按以射击（基础控制）。
- 音乐按钮会启用浏览器原生合成音，无外部音频资产。

## 数学与可解性

- 归零关：−1 永远可用，因此每个非负整数都有保底路径。
- ÷2 只接受偶数，√ 只接受完全平方数，mod 3 是真实余数；无效运算不消耗铅笔芯。
- “十点钟”目标关所有出生数字均不低于 10。若命中结果会低于 10，操作被拒绝并显示“会低于 10”；mod 3 在该页灰显。达到 10 即收集。
- Boss 有可见的“余数免疫”护甲，护甲拆完后才接收运算；页面切换清除旧投射物。

## 测试

`npm test` 覆盖核心 `apply(value, op, target)` 的整除、平方根、真实取模、目标 10 防降级、非安全输入与未知运算边界。

## 原创说明

本项目没有使用参考作品的代码、美术、音效或文字；绘制、规则实现和合成音均为本项目原创。


## 2.0 纸上实验室

竞技标题页选择「纸上实验室」，或打开 `dist/learn.html`。八页实验各有短演示与三道挑战，全部 24 题。按目录逐页解锁，完成页可重玩。点按工具即可操作；不计时、不扣分，有重置和撤销。声音默认关闭。

1. 正负数数轴：±1、±3 移动归零
2. 分数纸条：精确有理数加减，分子分母约分
3. 等式天平：两边同时加数或除以非零数
4. 坐标纸：点选节点或用箭头移动，匹配指定函数坐标
5. 匀速纸飞机：调速度并试飞，含厘米换米
6. 平衡力箱子：箱子已向右运动，合力为零保持原速度
7. 做功轨道：调整位移，计算指定同向恒拉力的功
8. 串联电路：更换电阻后合开关，开路电流为零

### 模型与数据

教学模式不含攻击。数学允许多路径，分数与方程使用整数有理数，不使用 eval。物理明确使用题目限定的理想模型；动画为缩放示意，不是数值积分。恒拉力不代表匀速，指定力的功不是净功；串联闭合回路各处电流相同。纯虚拟低压电路，不指导操作市电。

进度仅以 24 个布尔值存于 localStorage（paper-zero-lab-v1），不收集个人信息、不联网。存储被拒绝或内容损坏时安全降级；刷新后可能无法保留成绩，但当次仍可完成全部题目。

### 构建与验收

Node.js 18+，无依赖。`npm test` 包含竞技数学/Boss/弹道回归、41 条学科规则测试，以及八段演示、24 道挑战的 DOM 状态机模拟。`node test/arena-input-playthrough.cjs` 用模拟键鼠走完竞技五页；它不是实机浏览器测试。`npm run build` 跨平台复制完整 src 到 dist。

学科版已于 2026-10-16 在云端 Chrome 公开 Pages 实测：8 段演示与24题正常点击全部通过，显示24/24；刷新保持成绩。图形坐标点选、负系数方程、小数单位换算均通过。新增边界补丁另有状态机回归。既有竞技 v5 已在云端实际浏览器正常键鼠通关五页；本版保持竞技逻辑，仅整合 HUD v6 修正和学科入口。
