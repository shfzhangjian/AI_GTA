# 纸上归零 / Paper Zero

独立原创的静态 Canvas 2D 浏览器游戏。暖色书桌上的方格纸竞技场里，玩家操控火柴人，用四种运算符处理会走路的数字。

## 运行

直接打开 `dist/index.html`；或在项目根目录运行 `npm run build` 后用任意静态服务器打开 `dist/`。所有引用均使用相对路径，适合部署到 GitHub Pages 的子目录。

## 操作

- WASD：移动；鼠标：瞄准与射击；空格：冲刺；1–4：−1、÷2、√、mod 3；P/Esc：暂停。
- 移动端：拖动以瞄准、点按以射击（基础控制）。
- 音乐按钮会启用浏览器原生合成音，无外部音频资产。

## 数学与可解性

- 归零关：−1 永远可用，因此每个非负整数都有保底路径。
- ÷2 只接受偶数，√ 只接受完全平方数，mod 3 是真实余数；无效运算不消耗铅笔芯。
- “十点钟”目标关所有出生数字均不低于 10。若命中结果会低于 10，操作被拒绝并显示“会低于 10”；mod 3 在该页灰显。达到 10 即收集。
- Boss 有可见的“余数免疫”护甲，护甲拆完后才接收运算；页面切换清除旧投射物。

## 测试

`npm test` 覆盖核心 `apply(value, op, target)` 的整除、平方根、真实取模、目标 10 防降级、非安全输入与未知运算边界。
