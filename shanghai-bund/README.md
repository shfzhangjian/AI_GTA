# 漫步外滩 · A Little Shanghai

完全由原生 SVG 动态绘制的上海外滩像素漫步游戏。游戏场景不使用图片、Canvas、外部字体或第三方依赖。

[在线试玩](https://shfzhangjian.github.io/AI_GTA/shanghai-bund/) · [返回项目合集](../README.md)

![漫步外滩与无人机文字灯阵](./preview.png)

## 启动

直接用浏览器打开 `index.html`，或在本目录运行 `npm start` 后访问 http://127.0.0.1:4173 。需要 Node.js 才能使用本地服务器，直接打开 HTML 无需安装。

## 操作

- WASD / 方向键：自由漫步；点击步道：走到指定位置。
- 手机：右下方方向按钮移动，视野跟随玩家。
- E / 打卡按钮：在四个观景光点附近收藏风景，进度保存在当前浏览器。
- 散步清单右侧箭头：自动走向下一个未收藏的观景点。
- 控制栏：白昼 / 夜晚、人流、烟花、灯光秀、无人机、雨天、环境音效、全屏。

钟楼与右上角时钟采用同一个上海时间（Asia/Shanghai，UTC+8），逐秒同步。昼夜控制只改变场景氛围，不改变真实时间。白天晴天有飞机；夜晚有烟花、灯光秀和倒影。雨天所有人物撑伞，江面出现涟漪。烟花与灯光秀的开关状态在白天保留，切回夜晚后生效。

夜间新增「云端来信」无人机灯光表演，底部「无人机」按钮可独立开关。编队每 14 秒变换一幕：`我 ♥ 上海` → 东方明珠和江水轮廓 → `外滩 · 晚安`，每幕停留 9 秒、用 5 秒沿弧线聚散换阵。文字由手工笔画点阵转换成独立 SVG 灯点，不使用图片、Canvas 或字体栅格化。烟花在表演开启时避让到右侧天空。切换白昼会隐藏并暂停表演，重新开启无人机开关则从第一幕开始。

环境音效由 Web Audio 本地合成，默认关闭，首次点击音效按钮后开始。隐藏页面时暂停音效。尊重系统减少动态效果设置：关闭自动烟花和额外装饰动画，无人机保持第一幕静态灯阵，保留玩家、游船和天气等主要动态。

这是将外滩历史建筑与陆家嘴天际线放入同一画面的艺术化全景，建筑位置与比例并非实地测绘。

## 文件

- `index.html`：界面与操作入口。
- `style.css`：响应式布局与界面样式。
- `game.js`：SVG 场景、时钟、移动、天气、音效与打卡。
- `server.js`：无依赖的本地静态服务器，仅监听本机。

语法检查：`npm run check`。
