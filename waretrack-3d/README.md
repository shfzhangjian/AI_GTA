# 仓流智控 · 三维仓储指挥台

在浏览器中像操作策略游戏一样管理仓库。独立项目，使用 **Three.js + Vite + 原生 JavaScript**，无运行时 CDN、无账号、无后端服务要求。

参考：[Dilum Sanjaya 的仓库管理演示](https://x.com/DilumSanjaya/status/2106426962738880879)。实现基于 72 秒视频的场景与交互观察，3D 模型由程序独立构建，不使用视频贴图冒充三维界面。

[在线体验](https://shfzhangjian.github.io/AI_GTA/waretrack-3d/dist/) · [返回项目索引](../README.md)

## 启动

需要 Node.js 22.12+ 或 24+。

```sh
cd waretrack-3d
npm ci
npm run dev -- --port 5173
```

以上命令从仓库根目录运行。访问 http://127.0.0.1:5173 。

```sh
npm test          # 数据与调度自动测试
npm run build    # 输出 dist，可部署到静态服务器
npm run preview  # 预览构建产物
```

首次安装需要网络。安装后，本地运行不需要网络。请通过本地服务器访问，不要直接双击 index.html。

## 静态发布

仓库同时保留源码和 `dist/` 构建产物。构建使用相对资源路径，可直接通过 GitHub Pages 的 `waretrack-3d/dist/` 访问，也可以将整个 `dist/` 目录部署到其他静态服务器。修改源码后运行 `npm run build`，并一并提交更新后的构建产物。

第三方依赖许可见 [依赖许可说明](./docs/THIRD_PARTY_NOTICES.md)。

## 已实现

### 视频中的核心交互

- 全中文界面：导航、园区、详情、表单、报表、帮助、场景标识和预置业务数据；旧存档的预置英文名称自动以中文显示，保留业务编号与用户自填内容。

- 五个独立园区：河畔物流中心、北门分拨中心、东港冷链中心、南区交叉转运站、西门智能仓。
- 正交等距 3D 仓库，程序生成建筑、波纹屋顶、月台、货架、货盘、集装箱、树木、道路、卡车与有人驾驶叉车。
- 鼠标旋转、缩放、平移，工具栏旋转、俯视、复位，以及对象平滑定位。
- 场景点击选中仓库、货盘、叉车、卡车、月台；选中光环、运输作业路径与悬停提示。
- 卡车连续行驶：道路排队 → 入口转弯 → 园区通道 → 倒车入位 → 装卸 → 出口驶离；月台在车辆离场后才释放。
- 叉车从待命区出发，在暂存区与月台之间逐托盘搬运，完成后返回；货物随车移动，搬运进度驱动库存变化。
- 共用通道让行、实时速度与动作、车辆路径、跟随镜头；行驶位置随存档恢复。
- 园区容量、现场车辆、出库和上架统计；库存列表、低库存提醒、叉车电量与任务详情。
- 月台 / 叉车 / 卡车三个作业列表，以及联动的运输时间线和车辆详情。
- 跨五个园区搜索园区、商品、车辆、叉车、运输单；支持上下键选择结果。

### 补齐的可用业务闭环

- 新建入库或出库运输单，填写货物、数量、客户、目的地和承运商。
- 手动分配空闲月台和叉车，防止资源重复占用。
- 出库先预留、完成装车再扣库存，运输完成后签收；入库在卸货完成后增加库存。
- 可用库存、在途入库容量、非法数量校验；取消尚未发出的运输单会释放资源。
- 补货、叉车充电、1× / 5× / 15× 模拟、暂停和继续。
- 全园区库存报表、CSV 导出、通知与已读状态。
- 每 4 秒自动保存及离开页面保存；JSON 存档导入导出、存档结构校验与重置。
- 桌面浮层工作台和手机纵向布局；键盘焦点、原生对话框、表单校验。

## 推荐体验流程

1. 点击场景标题下的「运行车辆演示」，自动创建 2 托盘出库单并开始进场；需要一个空闲月台和有电量的叉车。
2. 在车辆详情点击「跟随车辆」，查看转弯、倒车停靠和离场；拖动场景或复位可结束跟随。
3. 切换 5× 可更快观察叉车往返搬货、库存扣减、卡车驶离与最终签收。1× 适合观察转向，15× 适合业务快进。
4. 点击「新建运输单」自行创建出库或入库任务，再分配空闲月台和叉车；入库在卸货后增加库存。
5. 试试库存不足、忙碌资源、取消订单和暂停；暂停同时停止业务与车辆运动。
6. 在行驶中导出 JSON 或刷新，验证恢复到保存位置。在「设置与存档」重置可以重新体验初始场景。

## 文件结构

- `src/scene.js`：Three.js 场景、建模、拾取、动画与镜头。
- `src/traffic.js`：道路坐标、圆角路径、倒车、行驶采样与速度变化。
- `src/store.js`：业务状态机、库存约束、调度、模拟、存档校验。
- `src/app.js`：工作台、详情、表单、搜索、报表与导出。
- `src/style.css`：视觉系统与响应式布局。
- `src/locale.js`：旧存档预置文案的中文显示。
- `tests/store.test.js`：14 项测试，覆盖行驶闭环、逐托盘搬运、路径边界、让行、暂停、存档、库存与调度约束。
- `docs/DESIGN.md`：设计规则。
- `docs/VERIFICATION.md`：交付验证记录。

## 数据边界

这是完整的**本地交互式仓储模拟应用**。所有业务操作真实修改并保存本地状态；没有连接真实 WMS、GPS、IoT、支付或多用户数据库。准时交付率明确标注为预置演示基线，其他核心数量来自模拟状态。车辆和叉车采用可视化路径动画，不是物理碰撞或工业控制引擎。刷新后恢复保存的进度，不在后台推算关闭页面期间的作业。

如需真实仓储系统，可保留 3D 场景和界面，将 `WarehouseStore` 的操作替换为后端 API / WebSocket 事件。
