# WareTrack 设计系统

## 方向
策略游戏式的工业调度工作台：蓝白低多边形微缩园区，少量悬浮面板，让业务状态与场景对象保持对应。布局以视频参考为依据，补充窄侧栏承载管理功能。

## 色彩
- 交互与品牌：#446ee9；悬停 #2f54c4。
- 页面与场景：#e5ebf6；卡片白色，低透明度。
- 文字：#25324b；次级文字 #8b96a9。
- 成功与作业：#33b779；低库存和等待为琥珀色。
- 货物采用纸箱米色、塑料箱蓝色；仓库结构采用深蓝。

## 字体
Avenir Next / SF Pro Display / 苹方 / 微软雅黑。数字使用高对比字重与紧凑字距；英文园区名与小型英文分区标注呼应参考。业务界面为中文。

## 布局
桌面顶部 62px 导航、左侧 61px 工具栏，顶部统计、右侧详情、底部时间线与资源列表。3D 场景延伸到面板背后。740px 以下改为滚动页面，3D 场景保留在上半屏，详情、跟踪与资源面板依次排列。

## 组件
卡片使用 11–15px 圆角、细边框与浅阴影；面板状态标签体积紧凑。按钮采用蓝色主操作和浅色次操作。表单使用原生控件与原生 dialog，支持焦点与 Esc。库存和运输状态不单独依赖颜色传达。

## 动效
三维镜头平滑定位和跟随。卡车按入口、前场通道、倒车月台、出口的连续路径行驶；叉车从待命区出发，在暂存区和月台之间逐托盘搬运，结束后返回。业务状态由实际行驶与搬运完成触发，车辆坐标、货盘状态和库存同步保存。共用通道采用让行控制，场景渲染在模拟位置之间平滑插值。暂停同时冻结车辆与业务；减少动态偏好关闭 CSS 装饰过渡。

## 统一物流地图
五座仓库同屏常驻，每个仓库保留独立的局部作业坐标，公共道路使用全局坐标；车辆在两种坐标间保持端点连续。顶部提供全网指标和调拨入口；总览收起右侧详情，点击对象后展开。地图仓库标签提供中文名称与定位按钮，关闭详情或点击全图总览即可回到全景。

自动调拨、手动调拨与原有出入库共用资源调度。源仓装车后扣库存，目标容量从创建时预留，目标叉车卸完后再加库存。道路运输按距离推进，目标资源不足时等位；镜头定位与业务推进相互独立。

## 精简界面与显隐
默认隐藏大统计卡片、侧栏、详情、运输时间线和作业列表，保留顶部在途摘要与必要操作。右下角提供九类区域独立开关、精简/全显预设及总显隐开关；总隐藏仅保留恢复入口。对象详情压缩为关键的源仓、目标仓、货品、货量、车速和交接状态。偏好随本地存档保存，窄屏仍以地图为主体。
