# The Balloon Test

Warm paper, graphite hardware, and one living latex color. The experiment should feel like an object photographed in a quiet studio.

- Color: warm ivory #eee9df, graphite #35372e, restrained accent chosen from each specimen.
- Typography: Noto Serif SC for title and narrative; DM Mono for measurements; DM Sans for controls. System fallbacks work offline.
- Layout: generous header margins; specimen right and pump left; reserved top and bottom HUD zones. Portrait moves the pump behind the specimen.
- Components: unboxed controls, fine rules, legible laboratory readouts, one compact result sheet. Visible focus and keyboard controls.

Physical pressure follows the Gent thin spherical membrane approximation. Displayed stretch is surface area stretch (lambda squared). The folded initial shape and local aneurysm are artistic deformations; the specimen's finite failure threshold is randomized independently of the pressure model. No external runtime resource is required besides optional Google Fonts.
