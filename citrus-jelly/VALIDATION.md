# 柑橘果冻验证记录

验证日期：2026-10-03。Windows 上的 Chrome，由 Playwright 驱动真实浏览器，原生 WebGPU 使用 Intel Gen-12LP 显卡。检查读取实际 GPU 错误、骨架和果实物理状态；截图来自运行中的应用。手机检查使用触屏与视口模拟。

## 渲染与入口

- 内嵌 JavaScript 与 WGSL 编译、多通道 WebGPU 渲染通过；没有 JavaScript 或 GPU 验证错误。
- 单文件可从 `file://` 直接打开，也可经 localhost HTTP 运行；页面没有外部资源请求。
- 缺少 `navigator.gpu` 时显示清晰的回退消息。
- 1440×1000 桌面、1024×768 平板、390×844 竖屏与 844×390 横屏布局均检查；手机面板默认折叠、控件可见。
- 调整像素密度后，桌面测试中的末段样本约 35 fps，渲染比例 0.88，最终仍为 4× MSAA。该值是本机短时采样，不是其他显卡或真实手机的帧率保证。

## 交互

- 鼠标抓取、慢速拉果实，确认枝梢弯曲后断开且果实仍留在手中；轻甩松手产生投掷速度。
- 落果可再次捡起并投掷；实际鼠标事件验证通过。
- 触摸摘取、双指缩放、手势结束后的指针清理通过。
- 配色切换时骨架坐标完全一致；暂停时模拟时间不变；重置恢复 28 枚悬果，重置视角恢复相机。
- 最大硬度与最低阻尼下的强摇、释放与长期静置仍保持有限值和连接的枝条。

## 掉落、碰撞与稳定性

- 中等成熟度的一组轻摇样本保留 26/28 枚果实；剧烈摇晃使 28 枚果实全部掉落，并释放少量叶片。
- 相同中等摇晃输入下，成熟度 0%、55%、100% 分别掉落 3、8、22 枚，确认滑块影响脱落难度。
- 空茎先等待，果实随后从小逐渐长大；再生结束恢复 28 枚悬果。
- 连续六轮摇晃与再生共掉落 168 枚；松散果实稳定在 34 枚，处于 64 枚池上限内，落叶池保持在 32 枚上限内。
- 强拉与重复摇晃后，所有坐标保持有限，根部坐标不变；采样中的最大枝条长度比约为 1.000000000000001，没有持续拉伸或断开的枝条。
- 落果与树干、其他落果、悬果的碰撞验证通过；落果撞击悬果时产生相应方向的位移。
- 地面冲击样本最大压缩约 21%；形变矩阵的相对体积误差约 1.1×10⁻¹⁵，最低表面与地面的差异仅在浮点精度范围内。
- 果堆能休眠，后续投掷碰撞能将其唤醒；稳定的旧果实逐渐淡出，反复掉落不增加无界对象。

以上数值来自指定的操作与采样。材质散射、屏幕空间折射和碰撞形变采用实时近似；不代表完整光路追踪或连续体软体求解。
