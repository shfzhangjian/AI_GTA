# 塞尔达风格开放世界动作游戏 (Three.js)

基于 Three.js + 原生 JavaScript (ES Modules) 的类塞尔达开放世界动作游戏。纯前端、无构建工具，直接打开 `index.html` 即可运行。

## 运行

需要本地静态服务器（ES Modules 要求）：

```bash
cd zelda-like
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 玩法

- **初始武器：树枝**。靠近火堆按 `E` 点燃火堆，并获得**火炬**。
- **随机刷新**：树枝、刀、石头、弓箭、肉，按 `E` 拾取。
- **怪物**：史莱姆 / 蝙蝠 / 狼 / 巨魔，随机刷新，数量随分数提升。
- **回血**：捡果子按 `E`，或杀羊拾取肉。
- 武器用 `1-4` 切换。

### 按键

| 按键 | 功能 |
|---|---|
| W/A/S/D | 移动 |
| Shift | 奔跑（耗耐力） |
| 鼠标左键 | 攻击（近战挥砍 / 远程投掷） |
| 鼠标右键 | 瞄准射击（弓/石头，自动锁定最近目标） |
| E | 拾取 / 交互（点燃火堆、吃果子、捡掉落） |
| 1-4 | 切换武器 |
| 空格 | 跳跃 |

## 目录结构

```
zelda-like/
├── index.html              # 入口：场景容器 + HUD (血条/耐力/武器槽/消息/小地图)
├── README.md
├── assets/
│   └── audio/              # 预留：真实音频文件（当前全部程序化合成，无需文件）
├── docs/                   # 预留：设计文档
└── js/
    ├── main.js             # 引导：创建 Game、小地图渲染、开始按钮、分数显示
    ├── core/
    │   ├── Game.js         # 场景/相机/灯光/主循环/HUD/死亡重启
    │   ├── Input.js        # 键盘鼠标输入
    │   └── Sfx.js          # Web Audio 程序化音效 + 循环背景音乐
    ├── player/
    │   ├── Player.js       # 移动/跳跃/耐力/攻击判定/拾取/受伤回血
    │   └── Weapons.js      # 武器定义：树枝/火炬/刀/弓/石头（数值+程序化3D模型）
    ├── world/
    │   └── World.js        # 地形/树/草/火堆/果子/羊/掉落/投射物 + 资源刷新
    └── monsters/
        └── MonsterManager.js  # 怪物模板(史莱姆/蝙蝠/狼/巨魔)/刷怪/追击/AI
```

## 后续扩展路线

1. **存档**：用 `localStorage` 保存分数/解锁武器/火堆状态。
2. **碰撞**：树/石头当前不参与物理碰撞，可加简单圆形碰撞。
3. **真实音效**：在 `assets/audio` 放文件，扩展 `Sfx.js` 的 `play()` 支持 `Audio` 标签。
4. **敌人 AI**：巡逻路径、被击退硬直、群体包围。
5. **任务系统**：docs/ 中增加任务设计，`Game.js` 加 quest 状态。
6. **昼夜循环**：`Game.js` 中调 `hemi`/`sun` 颜色与强度。
7. **更多生物**：鸡、野猪、宝箱。

### 模块约定

- 所有模块通过 `import` 互相引用，游戏对象作为依赖注入（`new Player(game)`）。
- 世界实体统一用 `THREE.Group` + `userData` 携带数据，便于扩展。
- 新增武器：在 `Weapons.js` 的 `WEAPONS` 加一项即可（模型 + 数值 + 类型 melee/ranged）。
- 新增怪物：在 `MonsterManager.js` 的 `TEMPLATES` 加一项，并在 `POOL` 配权重。
