# 潮屿 · TIDELANDS

一个可在浏览器中游玩的 3D 热带浮岛探索游戏。场景参考用户提供的 [Sonia 视频](https://x.com/sonia_code/status/2106218179978785001/video/1)：圆形海水切片、云海、木屋与栈桥、棕榈林、恐龙头骨瀑布、肋骨拱廊、望海塔和火山。

[在线试玩](https://shfzhangjian.github.io/AI_GTA/tropical-island/) · [返回项目合集](../README.md)

视频主要展示箱庭场景，没有说明游戏规则。本项目在重建场景的基础上增加了驾驶、寻宝、修复和通关流程。所有模型均为程序生成，不依赖远程素材或 API；参考视频仅用于分析，未作为游戏画面播放。场景是一套独立重建的风格化模型，并非原视频资产的逐像素复制。

## 运行

需要 Node.js 18 或更高版本，不需要安装依赖。

```powershell
cd tropical-island
npm start
```

打开 http://127.0.0.1:5188 。也可双击 `开始游戏.cmd` 后打开终端显示的网址。端口可用 `PORT` 环境变量修改。服务器仅监听本机。

本目录的 `index.html` 及其相对路径资源可直接部署到 GitHub Pages，无需运行 Node.js 服务或编译。原生 ES Modules 需要 HTTP 环境，不能直接以 `file://` 打开。

## 玩法

1. 点击 **启航探索**。
2. 点击海面或金色珍珠，自动航行；也可用 WASD / 方向键驾驶。
3. 靠近珍珠即可拾取。船会避开主岛、四座礁岛和海水边界。
4. 点击地标，用 2 颗珍珠点亮它。共有 8 颗珍珠、4 处可修复地标。
5. 完成全部修复后通关，可继续自由探索、看暮色或保存 PNG 照片。

拖动旋转、滚轮缩放、右键拖动平移。底部按钮提供全岛视角、自动环绕、拍照和全屏。右上角提供晴日 / 暮色、声音和指南。手机可点击航行，触摸设备额外显示方向按钮。Escape 关闭面板或暂停。

进度自动保存于浏览器 localStorage。同一地址重新打开即可续玩。暂停面板中的“重新开始旅程”需点击两次以确认清除。测试使用 `?qa=1` 的独立存档，不改变普通游戏的存档。

## 技术

- Three.js 0.185.1 / WebGL：光照、阴影、几何体、粒子和镜头控制。
- 自定义 GLSL：海面波纹与焦散、水体侧面、云海、瀑布和浪花。
- 自定义模型：头骨与牙齿、肋骨拱廊、木屋、木塔、栈桥、棕榈、叶片、火山和帆船。
- A* 寻路、连续水域碰撞、资源与通关状态、存档校验。
- Web Audio：程序生成海浪与低音量环境音，以及拾取 / 修复提示音。声音默认关闭。
- 原生 HTML/CSS/ES Modules；本地依赖，运行时无需联网。

## 检查

```powershell
npm test
```

测试覆盖全部珍珠的可达性、主岛与礁岛避障、完整收集 / 修复 / 通关、重复修复、暂停、资源不足、越界和损坏存档。浏览器还验证了真实点击航行、地标切换、修复扣费、通关弹窗、重新加载续玩、昼夜和 390 × 844 手机布局。

## 文件

- `src/world.js`：场景与动画。
- `src/game-state.js`：独立游戏规则与导航。
- `src/main.js`：界面、输入、保存和事件反馈。
- `src/audio.js`：声音。
- `vendor/`：Three.js 与官方辅助模块；许可证见 `vendor/LICENSE`。
- `qa/`：验证记录与浏览器实机预览。参考视频仅作为开发时的对照资料，不随游戏发布。

建议使用支持 WebGL 的 Chrome 或 Edge。较旧的设备可关闭自动环绕并缩小窗口；照片通过浏览器下载保存。
