# 葫芦娃救爷爷

水墨风 Three.js 弓箭防守游戏。玩家操控葫芦藤弓守住洞府封印，按住拖动预览虚线弹道和落点，松手射击妖怪与封印。

## 玩法

- 按住战场拖动：预览落点和低抛物线轨迹。
- 松手：放箭。
- 收起/展开：折叠底部属性面板，扩大视野。
- 空格：自动攻击最近目标。
- 升级：使用灵豆提升箭伤、箭速、葫芦气和会心。
- 技能：解锁葫芦娃技能，消耗葫芦气改变战局。

## 本地运行

```bash
python3 -m http.server 8080
```

然后打开 <http://127.0.0.1:8080/>。

## 结构

- `index.html`：游戏入口。
- `src/`：游戏源码，按音效、场景、实体、状态、UI、弹道等模块拆分。
- `assets/sprites/`：免费游戏精灵素材。
- `libs/three.module.js`：本地 Three.js 模块，保证 GitHub Pages 零构建运行。
- `docs/game-design.md`：策划与扩展说明。
- `docs/asset-credits.md`：素材来源与授权记录。

## 说明

项目为纯静态网页，可直接部署在 GitHub Pages 子目录下，无需构建步骤。
