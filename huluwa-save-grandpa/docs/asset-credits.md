# 素材来源

项目使用免费素材时优先选用 CC0，方便后续改造、发布和替换。

## 已接入

- 主角弓手：`2D animated Archer Spritesheet`，作者 `mh-studios`，来源 `https://opengameart.org/content/2d-animated-archer-spritesheet`，授权 `CC0`。
- 行走怪物：`Bevouliin Free Sprite Sheets Monster Game Asset`，作者 `bevouliin.com`，来源 `https://opengameart.org/content/bevouliin-free-sprite-sheets-monster-game-asset`，授权 `CC0`。
- 独眼怪物：`Bevouliin Free Enemy villain Monster Game Asset for Game developers`，作者 `bevouliin.com`，来源 `https://opengameart.org/content/bevouliin-free-enemy-villain-monster-game-asset-for-game-developers`，授权 `CC0`。
- 爷爷 NPC：`Old Man 32x32 Overflow Sprite from FOSS Lightstone Project`，作者 `Syrsly`，来源 `https://opengameart.org/content/old-man-32x32-overflow-sprite-from-foss-lightstone-project`，授权 `CC0 / OGA-BY 3.0`，本项目按 CC0 使用。

## 注意

不要直接使用官方葫芦娃动画角色图、截图或同人包作为游戏资产。当前项目使用“葫芦救爷爷”的主题表达和免费素材改造位，便于后续换成原创角色图集。
