# 《葫芦娃救爷爷》策划草案

## 定位

水墨横版弓箭防守游戏。玩家在左侧控制七娃的葫芦藤弓，抵挡从洞府方向压来的妖兵，击破封印并救出爷爷。

## 核心循环

1. 按住战场显示低弧线虚轨迹和落点，松手射出藤箭。
2. 击败敌人获得灵豆和葫芦气，同时削弱洞府封印。
3. 用灵豆升级弓、弦、气海和符箭匣。
4. 解锁大娃、二娃、三娃、火娃技能，处理密集波次。
5. 破除三关封印后完成营救。

## 玩法系统

- 弓箭：基础攻击，受青藤弓、金线弦、符箭匣影响。
- 轨迹：瞄准预览和真实箭矢共用低抛物线算法，减少高弧遮挡并提升落点判断。
- 敌阵：靶甲妖兵抗线，蛇影斥候高速突进，铜鼓妖兵提供中等压力，蝎甲卫与蛇府术士作为高血量目标。
- 技能：大娃范围震击，二娃提高会心，三娃降低爷爷受伤，火娃进行区域爆发。
- 资源：灵豆用于升级和解锁技能，葫芦气用于施放技能，山玉作为通关奖励。
- 音效：使用 Web Audio 合成短音效，覆盖射箭、命中、暴击、技能、升级、受伤、破关和胜负反馈；后续可替换为同名音频素材包。

## 美术方向

精密卡通结构结合中国水墨层次。远山用淡墨洗染，地面和树木保留笔触边缘，角色与敌人使用清晰轮廓和靶甲符纹，确保战斗信息可读。

## 代码结构

- `src/main.js`：启动游戏，连接状态、场景和界面。
- `src/game/config.js`：关卡、数值、敌人、升级和技能配置。
- `src/game/state.js`：资源、关卡、冷却、胜负等纯状态逻辑。
- `src/game/scene.js`：Three.js 场景、输入、战斗循环和特效。
- `src/game/entities.js`：敌人、箭矢、粒子和伤害数字。
- `src/game/art.js`：程序化水墨纹理与精灵绘制。
- `src/game/audio.js`：浏览器合成音效与音效开关。
- `src/game/trajectory.js`：低抛物线、落点和瞄准预览计算。
- `src/game/ui.js`：顶部战况、底部升级栏、技能栏和战报。
