# 手绘五子棋

一个使用 HTML、CSS 和 Three.js 制作的手绘风格五子棋小游戏，支持桌面和手机浏览器直接游玩。

## 特色

- 支持人机对战和双人对战
- 每局从 10 种动物/植物角色中随机抽取 2 种作为双方棋子
- 手机端自动切换为平面俯视棋盘，并放大角色、扩大棋盘间隔以适配竖屏触控
- 棋子脚底对齐棋盘交叉点，移动端与桌面端都按交叉点落子
- 新落子夹住对方连续两个角色时会吃子、得分，并触发爆炸打击消除效果
- 提示开关会推荐下步落子、标出危险点，并显示吃子规则
- 攻击按钮只会赶走对方角色：一群小动物从棋盘边缘扇形冲入，围到目标身边后再把它追出棋盘
- 捣乱按钮会叫来飞机，随机投下炮弹炸坏棋盘；被毁坏的交叉点不能继续落子
- 胜利后赢家变成快乐表情，周围同类小人会随机跳跃、击掌、发呆、碰撞摔倒再爬起
- 胜利时会放烟花，并用烟花字组成胜利提示，同时询问是否继续下一局
- 使用 Web Audio API 程序生成落子、打击、爆炸、攻击、胜利音效

## 本地运行

```bash
python -m http.server 5173
```

然后访问：

```text
http://127.0.0.1:5173/gomoku-threejs/
```

如果在当前目录内单独启动：

```bash
cd gomoku-threejs
python -m http.server 5173
```

访问：

```text
http://127.0.0.1:5173/
```

## 技术栈

- HTML + CSS
- Three.js 0.164.1 CDN ES Module
- Web Audio API
- 纯静态文件，无需构建步骤
