# 汽车智慧工厂数字孪生可视化大屏

纯 **HTML + Three.js + ECharts + datav 风格深色科技主题** 实现的汽车工厂三维可视化大屏：
真实还原厂区五大车间场景与监控布局，并动态展现冲压 → 焊装 → 涂装 → 总装 → 仓储物流的完整生产过程。

## 运行方式

纯静态工程，无构建步骤。任选其一：

```bash
# 方式 1：Python
python -m http.server 8000
# 方式 2：Node
npx serve .
```

浏览器打开 `http://localhost:8000/index.html`（依赖 CDN：three@0.160 / echarts@5.5，需联网首次加载）。
建议 Chrome/Edge，分辨率 ≥ 1600×900。

## 目录结构

```
index.html              大屏骨架：顶栏 / 左右面板 / 三维视口 / 播报条
css/datav.css           深蓝 DataV 主题：切角面板、发光描边、扫描线监控、气泡标签
js/
  data.js               模拟数据层：车间/设备/生产/经营/营收，每秒 tick 推进实时数据
  main.js               编排：视图状态机（factory | interior）、相机一镜到底、拾取、标签、巡航
  ui/charts.js          五大面板的全部 ECharts 配置
  ui/hud.js             时钟 / 实时告警 / 工位状态格 / 播报 / 关键指标
  scene/
    app.js              渲染器 / 相机 / OrbitControls / 射线拾取 / 飞行插值
    builders.js         共享低模资产：厂房外壳、机械臂、传送带、汽车、AGV、压力机等
    factory.js          厂区全景：五大厂房、环路、AGV 环线、发运场、烟囱、数据地坪、跨车间流光环带
    workshops.js        车间室内：四条产线动画 + Ghost 透视/外观替身/2 秒淡入淡出切换
```

## 五大功能模块（顶部导航）

| 模块 | 内容 |
|---|---|
| 工厂总览 | 车间生产流程链（可点击直达车间）、企业年度营收、产品销量统计 |
| 经营概况 | 企业整体经营 KPI、各区域营收/利润对比、各区域指标完成率 |
| 生产概况 | 生产计划完成对比、产品状态分布（完成/在制/滞留/在库）、出入库趋势 |
| 车间概况 | 车间选择、详细数据（面积/产线/节拍/OEE/能耗）、产量节拍趋势、**进入车间室内空间** |
| 设备概况 | 设备总数/运行/待机/故障、各车间设备状态堆叠、OEE 玫瑰图 |

## 三维交互

- **工厂全景**：数字孪生数据地坪 + 车间外观，聚焦车间半透视可见内部产线，AGV/物流/光带流动；
  点击建筑或车间名标签 → 一镜到底穿墙进入室内。
- **车间室内**：
  - 冲压：4 台伺服压力机滑块往复 + 板料传送 + 模具 AGV
  - 焊装：12 台机械臂集群作业 + 实时焊花粒子 + 白车身 EMS 滑橇输送 + 测量门扫描
  - 涂装：车身连续吊具输送（前处理→电泳→烘房→色漆→清漆→烘干蛇形环链）
  - 总装：内饰双线 + 底盘合装岛升降合装 + 最终线 + 转毂检测 + 成品下线驶出
  - 仓储：立库堆垛机巷道 + ANF 无人配送车 + 收发货月台
- **设备监管**：室内点击设备弹出信息浮窗（状态/OEE/温度/加工件数），故障设备红色气泡常驻告警。
- 左键旋转 / 滚轮缩放 / 右键平移；空闲 20s 自动巡航；面包屑一键返回总览。
- 右侧面板与三维联动：实时告警、工位状态格、监控画面、今日指标实时刷新。

## 说明

- `shots/` 为运行验证截图（headless Chrome 实拍）：工厂总览、焊装/总装室内、设备概况、返回总览。
- 数据为内置模拟数据层（`data.js` 每秒 tick），接真实 MES/SCADA 时只需替换该文件的数据源。
