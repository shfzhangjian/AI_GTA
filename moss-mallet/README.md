# 苔苔敲敲岛 · Moss & Mallet

参考等角积木森林的 3D 连锁敲砖游戏。HTML + Three.js r165 + SVG 界面，Web Audio 本地合成敲击、连消、爆破、通关音效与轻柔森林旋律。

**[在线试玩](https://shfzhangjian.github.io/AI_GTA/moss-mallet/)** · [返回游戏合集](../)

![游戏预览](./preview-desktop.jpg)

## 运行

在此目录运行 `npm start`，浏览器打开 http://localhost:8788 。无需安装依赖；Three.js 已随项目本地附带。也可用任意静态 HTTP 服务器托管此目录，不能直接双击 HTML 使用 file://。

Windows 也可以双击 `start-game.cmd` 启动服务，再打开上述地址。手机与电脑在同一 Wi-Fi 下，可以用电脑局域网 IP 和端口 8788 访问，例如 `http://电脑IP:8788`。

## 玩法

- 点击「开始探险」，再点击砖块。四向相邻同类一起消除，消耗 1 次敲击；消除后砖块下落并补齐。
- 收齐本关青苔和晶石目标进入下一关，共五关；没有倒计时。
- 木锤连消 5 块获得蘑菇炸弹，连消 8 块额外获得彩虹魔法。
- 蘑菇工具清除点击位置周围 3 × 3；彩虹工具清除全岛与点击目标同类的砖块。使用工具同样消耗 1 次敲击。
- 棋盘上的蘑菇砖触发范围爆破；彩虹砖清除所在行列；特殊砖可相互触发。
- 重排消耗 2 次敲击。敲击耗尽前完成目标获得剩余次数积分奖励。
- 键盘：1 / 2 / 3 选择工具，P 暂停，M 静音，R 重新开始；支持手机触控。
- 手机双指缩放棋盘，放大后单指拖动；轻点砖块开采，拖动不会误敲。手机竖屏、横屏与桌面均使用全屏游戏 HUD。

## 文件

`world.js`：圆角矿块、分层浮岛、树木、兔子、池塘、阴影与粒子效果。`game.js`：连通区域搜索、特殊砖连锁、下落补齐、五关目标、工具与交互。`audio.js`：本地合成音效。`index.html` / `style.css`：SVG 图标、响应式中文界面与弹窗。

`npm test` 检查连通区域、工具优先级、特殊砖接力，以及 500 轮补块后的棋盘完整性。
