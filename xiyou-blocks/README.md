# 西游 · 补天方阵

原创中国神话落块消除游戏。静态 HTML / CSS / JavaScript 与本地打包的 Three.js，无 CDN、无账号、无网络依赖。

## 运行

Node.js 18+ 用于测试。游戏可用任意静态服务器运行：

    npm start

打开 http://localhost:4173 。

## 操作

- ← / →：移动；↑ / X：顺时针旋转；Z：逆时针旋转
- ↓：软降；空格：硬降；C / Shift：保留；P / Escape：暂停
- F：满 100 灵气后，清除最下方两行有石行；每消一行积攒 25 灵气
- M：声音开关；Enter：开始、继续或重新开始
- 手机使用屏幕下方触屏按键与右侧神通按钮

一至四行分别触发碎玉、祥云、真火、金箍棒特效。每 10 行升级，重力加快；第三境切换天宫配色。最高分仅保存在当前浏览器本地。音效和五声音阶环境音乐由 Web Audio 实时生成，默认静音。尊重系统减少动态效果设置。

## 规则与测试

10×20 棋盘；七袋随机；SRS 踢墙；幽灵落点；500ms 锁定延迟、最多 15 次重置；每块一次保留；连消加分。普通行奖励 100 / 300 / 500 / 800 × 当前级别，连消另加分。满蓄力技能奖励 100 × 行数 × 级别，不回充灵气。

    npm test

29 项自动测试与 100,000 步规则压力测试通过。浏览器 QA 记录见 QA.md。
