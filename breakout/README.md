# 砖块破坏者 · Breakout Elements

模块化 HTML5 Canvas 打砖块引擎：**元素级砖块建模 / 子步连续碰撞 / 元素专属破坏物理与特效 / WebAudio 合成音效 / 连击积分算法 / 顶部随机英文单词砖 / 掉落道具（多球·挡板伸缩·火球子弹）/ 屏幕自适应 / 全生命周期事件调试**。

## 运行

```
双击 start.bat        （自动选 Python 或 npx serve，端口 8765）
# 或手动：
python -m http.server 8765
```

打开 <http://localhost:8765>。调试模式：<http://localhost:8765/?debug=1> 或运行中按 **F2**。

> ES Module + fetch 需要 http 环境，直接双击 index.html（file://）无法运行。

## 操作

| 按键 | 功能 |
|---|---|
| ←→ / A D / 鼠标触摸 | 移动挡板 |
| 空格 / 点击 | 发射小球；**火球模式下 = 发射子弹**（也可按 X） |

| F2 | 调试面板 + 碰撞盒/速度矢量/轨迹预测覆盖层 |

## 屏幕自适应

画布逻辑分辨率固定 960×640（游戏代码零适配成本），CSS 按 `min(视口宽, 视口高×3:2)` 等比缩放，任意屏幕/窗口大小完整显示不拉伸；指针坐标经 `getBoundingClientRect` 逆变换映射回逻辑空间。

## 单词砖与掉落道具

**顶部单词砖**：每次加载关卡在顶部随机拼出一个英文单词（词库见 `src/level/wordFactory.js`），每个字母砖独立随机材质且相邻不重复，15% 概率是炸药桶。**整词摧毁 → 额外奖励分 + 必掉一件道具**。

| 道具 | 效果 |
|---|---|
| ×3 多球 | 每颗现役球分裂出两颗（上限 6 颗） |
| + + 加长 | 挡板 +60%，持续 10s |
| - 缩短 | 挡板 -38%（负面道具），持续 8s |
| ✹ 火球 | 6s：小球**穿透砖块**并造成 3 倍伤害、火焰拖尾；挡板**接球自动开炮**，空格/X 手动发射子弹，子弹可破坏砖块 |

掉落概率：炸药桶必掉、金块 35%、其他元素 10%。生效中的道具在左上角显示倒计时条。

## 砖块建模（自由建模）

砖块 = **字符网格**，每格引用一种元素；关卡 JSON 里直接写 `cells`，或放进 `models` 共享模型库多处复用：

```json
"models": { "guard": { "cells": ["W.W", "WMW"] } },
"bricks": [
  { "name": "核心", "x": 408, "y": 96, "cells": ["MM$$MM", "MWXXWM", "MM$$MM"] },
  { "name": "左卫", "x": 168, "y": 168, "model": "guard" }
]
```

单字符别名：`G`玻璃 `S`石 `I`冰 `W`木 `M`金属 `$`金 `X`炸药，`.`/空格=空洞；也支持逗号分隔写全名 `"stone,glass"`。

### 元素属性（src/entities/element.js）

| 元素 | HP | 分值 | 质量 | 破坏特效 | 音效 | 特殊物理 |
|---|---|---|---|---|---|---|
| 玻璃 glass | 1 | 12 | 1 | 高速碎片 shatter | 高频碎裂 | — |
| 冰块 ice | 2 | 14 | 2 | 冰晶碎片 | 冰裂 | — |
| 石块 stone | 2 | 10 | 3 | 粉尘 dust | 闷响 | — |
| 木块 wood | 2 | 8 | 2 | 木刺 splinter（高重力） | 敲击 | — |
| 金属 metal | 4 | 25 | 6 | 火花 spark | 金属振鸣 | — |
| 金块 gold | 3 | 60 | 5 | 金色火花 | 三连琶音 | — |
| 炸药桶 explosive | 1 | 40 | 2 | 火球+冲击波环+震屏 | 低频爆轰 | **半径 80 / 伤害 4 / 延迟 0.12s → 连锁爆炸** |

新增元素 = 在 `ELEMENTS` 注册表加一条定义（必要时在 `particles.js`/`audioEngine.js` 加特效预设与音色），建模即可引用。

## 核心算法

- **运动与碰撞**：固定子步 1/120s，球每步位移 < 半径 ⇒ 离散检测等效连续碰撞，高速不穿模；圆-AABB 求交取穿透深度法线反弹，反弹后限制最小垂直速度防水平死循环。
- **挡板手感**：击中偏移 r∈[-1,1] → 反弹角 r×60°，叠加挡板横向动量。
- **连锁爆炸**：炸药被毁 → 进入延迟起爆队列（`pendingExplosions`），到时对半径内所有元素做点-矩形距离判定并施加伤害；波及的炸药再次入队 ⇒ 自然形成链式爆破节奏。
- **积分**：`得分 = 基础分 × (1 + 球速/1200) × min(1 + (连击-1)×0.25, 5)`；连击窗口 1.6s，超时清零；未摧毁的受击也计小额 graze 分。

## 调试模式（F2 / ?debug=1）

- **事件日志**：加载耗时、砖块生成、元素损伤/摧毁、每次碰撞、爆炸与连锁、积分结算、状态机切换，按类别着色滚动显示（含启动以来的历史）。
- **实时指标**：FPS、球位置/速度矢量、存活元素数、粒子数、待爆队列、连击倍率。
- **画布覆盖层**：绿色碰撞盒、红色球体包围圆、粉色速度矢量、黄色虚线轨迹预测（模拟最多 7 次反弹）。
- **控制台 API**：`__BREAKOUT__.game.debugKillAll()` 清空关卡、`debugNextLevel()` 跳关、`debugDrop('fire'|'multi'|'wide'|'narrow')` 强制掉落道具、`bus.on('*', ...)` 订阅全部事件。

## 扩展指引

- **新关卡**：复制 `levels/levelN.json`，把文件加入 `levelLoader.js` 的 `LEVEL_FILES`。
- **调手感**：全部参数集中在 `config/constants.js`（子步长、球速上限、连击窗口等）。
- **自定义底图**：见 `assets/bg/README.md`；音效替换见 `assets/audio/README.md`。
