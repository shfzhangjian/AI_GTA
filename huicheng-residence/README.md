# 汇成上东 · 29 栋 507 空间档案

基于用户提供的家具布置图、原始结构图及水路布置图制作的 HTML + Three.js 户型浏览器。

## 打开

- [在线浏览](https://shfzhangjian.github.io/AI_GTA/huicheng-residence/)：GitHub Pages 使用已内嵌全部资源的 `index.html`，支持仓库子目录。
- [离线文件](./汇成上东-离线预览.html)：下载后可直接双击打开。

直接双击 **`汇成上东-离线预览.html`** 即可使用。模型、程序、材质与三张图纸都已内嵌，无需联网或启动服务。

开发预览：双击 `启动预览.cmd`，然后访问 http://127.0.0.1:5347 。需要已安装 Node.js。本项目自带 Three.js，不需要安装依赖或联网下载资源。

也可以在项目目录运行 `node server.mjs`。设置环境变量 `PORT` 可改端口。本地服务默认读取 `index.source.html` 与 `src/`，便于编辑源码后刷新预览。

重新生成离线版与 GitHub Pages 入口：运行 `npm install` 安装构建工具，然后运行 `npm run build:standalone`；命令同步生成 `index.html` 和 `汇成上东-离线预览.html`。浏览已提交的页面无需安装依赖或构建。

## 功能

- **平面**：可缩放、平移、点击房间，查看家具轮廓、面积和总尺寸；显示设置中可叠加原图对照。
- **3D 总览**：拖动旋转、滚轮缩放、右键平移；房间列表快速聚焦；可切换剖切、半高、完整墙体、家具、标签与日光 / 暮光。
- **墙面材质**：显示设置中可切换暖白哑光乳胶漆、浅灰微水泥和米色艺术涂料；采用细微凹凸、粗糙度和色差纹理，按真实长度铺贴，切换墙高时纹理不拉伸。材质选择自动保存，并同步应用于 3D 与室内游走。材质由程序生成，离线可用。
- **室内游走**：W/A/S/D 移动，Shift 加速，拖动鼠标或方向键转向；可选鼠标锁定，Esc 释放或退出；E 或点击门扇开关门。墙、窗、家具和关闭门扇有碰撞。移动端提供方向按钮。
- **房间导航**：左侧空间列表或右下角小地图快速到达 11 个空间。
- **自动导览**：12 个视点，支持暂停、上下切换与退出；在房间间切换视点，避免穿墙的自动移动。
- **原始图纸**：内置三张原图，切换查看。
- **画面导出**：右上角相机按钮保存平面或 3D / 室内视角 PNG。
- 快捷键 1 / 2 / 3 切换视图。

## 重建依据与边界

总宽 14.44 m，总深 10.87 m，图示层高 2.77 m。坐标按原图像素描摹并以总宽校准到米，家具、墙体、门窗、房间轮廓共享同一坐标源。原图尺寸标注可作为校核依据。

模型包含书房、卫生间、衣帽间、两间卧室、厨房、餐厅、客厅及三处阳台。家具包括组合沙发、茶几、台灯、电视柜、六人餐桌、餐边柜、照片墙、端部高柜、U 形厨房、单槽水池、双眼燃气灶、侧吸油烟机、微波炉、烤箱、小家电、床具、衣柜、玻璃书柜、书房长书桌、平板、地球仪、透明收纳架、木凳、打印机、飘窗、玻璃淋浴房、坐便器、浴室柜、镜柜、洗衣机、洗衣池、窗帘、灯具、植物及空调。

书房、主卧、卫生间、餐厅、厨房与入户门的布局、家具类型、配色和主要细节依据用户补充的实拍照片，家具尺寸结合图纸比例与照片估算；走廊挂画使用用户提供的原画。其他未提供实拍的空间采用合理默认造型。图纸照片描摹无法替代 CAD 测量，模型面积含阳台、墙体及飘窗，用于空间浏览，不作为施工或产权面积数据。

餐厅按十张餐厨实拍中的对应关系更新：灰米色墙面上排列 26 个黑白与金色相框，每个相框分别采样原照片里的画面；整排白木纹餐边柜带银色横向拉手，一端连接双门高柜与开放格。柜面保留书籍、四色小抽屉、透明收纳盒、瓶罐、笔筒和摄像头；白色桌面搭配深色细框餐椅、桌面台灯与学习用品。六人桌椅位置仍按布置图，照片未拍全的部分按比例估算。两处入口之间补上窄型波纹玻璃高柜、地图挂板和挂袋；吊顶为白色跌级边线，圆形蓝银色灯具有分层圆环和底部金色饰盘。照片墙、学习挂图和地图所用的四张原始照片保持完整，并内嵌离线版，重复采样共用照片纹理。

厨房按实拍重建白色吊柜、灰色地柜、银色弧形拉手、浅色石材操作台、白色横向瓷砖和方格吊顶。深色双扇窗下为单槽不锈钢水池、弯管龙头与窗台盆栽，旁边补上壁挂热水器及排气管。北侧黑色双眼灶带木柄炒锅、带盖汤锅和前置旋钮，上方为带银色包边的黑色侧吸油烟机；烟机局部画面采样原照片。右侧按照片改为微波炉开放柜、台面烤箱、小型空气炸锅、水壶与多层置物架，替换此前的示意冰箱。保留调味瓶、碗杯、砧板、刀架、锅盖架和挂放厨具。设施尺寸结合现有图纸和照片估算。

厨房入口为白银色玻璃推拉门，生活阳台入口为深色边框玻璃推拉门与学习挂图；两扇门均沿双轨叠合滑动。初始打开，靠近按 E 或点击门扇开关，关闭时封住通道；平面图、动画和碰撞同步更新。生活阳台的地面按照片改为带小菱形角饰的暖橙色砖。已检查门扇叠合、关闭碰撞、打开通行以及全屋 11 个空间的连通性。

入户大门按用户实拍重建为深红棕色防盗门与门框，三段凹凸门板、包边、右侧黑色电子锁及铜金色执手、猫眼和白色数显装置。门上的人物贴纸、圆形磁贴与彩色磁力片直接采样完整原照片，用透视纹理坐标对齐到门板；门板线条、磁力片、锁体和执手分别有实际厚度。照片未拍全的底端按现有门板延续。由室内看，门轴在左侧、门锁在右侧，向内开启；门扇与开关动画有同步碰撞。游走底部「入户大门」可直达门前，按 E 或点击门板开关。原照片已内嵌到离线版。

书房已按实拍替换此前的示意家具。北侧为四门灰白玻璃书柜及约 1.33 × 2.02 米白色收纳床：书柜内有书籍、叠放资料、小兔与机器人玩具，床具含抽屉拉手、双段软包床头、平整蓝色蜂窝凉感垫。床上的枕头、褶皱被子与叠放物已按最新标注清空，平面图同步移除床品符号。窗边长书桌分为高低两段，保留平板、细杆白色台灯、双铃闹钟、书籍、三层透明书架、两层地球仪架、文具盒和整理后的纸张；桌下有抽屉推车、木凳、木长凳、背包及纸篓。门旁四层波纹收纳柜含资料、打印机与球形摄像头。地面采用深红木纹，室内墙面为灰米色，补全灰色环扣窗帘、白纱、香槟色壁挂空调及管线、白色横槽门、深色踢脚线、白色顶角线和花形吸顶灯。柜前空气净化器及折叠支架也已建模。九宫格相框、挂历和一册书封直接使用用户照片中的内容，原照片保持完整，通过纹理坐标校正透视；离线版内嵌所有纹理。点击书房进入整理后的书桌视角，自动导览的第 6 个视点可查看床与书柜。

次卧书桌及其配套椅子、桌面物品已移除。休闲阳台清空休闲椅、边桌及全部绿植，保留门窗、纱帘与建筑结构。房间说明、平面图、3D、游走碰撞和导览同步更新。

走廊北端墙面挂入用户提供的黄绿抽象画，使用原始照片及透视校正的纹理坐标，配黑色画框；原图已内嵌到离线版。室内游走底部的「走廊挂画」可直接到达画前。卫生间门改为右侧铰链向内开启 90°，完全打开后收至卫生间侧墙内侧；门扇、把手留出墙面间隙，开关动画、平面开启轨迹及碰撞同步更新。

主卧按实拍建模：深红木地板、米色三段软包床头、米白床架与平整床单、铺平的浅绿被子、粉色及条纹枕头、星星玩偶、粉灰两块床边护栏；搭配双抽屉米色床头柜、浅紫收纳柜、循环风扇、黄色拉杆箱、香槟色壁挂空调、米色环扣流苏窗帘和白纱、金色花形水晶灯。北侧床头墙为米色底紫色波纹墙纸，其他墙面采用细微凹凸暖米色纹理。此前主卧的示意书桌、地毯、绿植与床头灯已替换。按最新标注铺平床品，移除床边木椅及搭放衣物；平面图与游走碰撞同步移除。主卧前的过道交界处原本没有门，已移除此前误设的门扇、门框与开门轨迹，保留开放通道及正常通行。

衣帽间入口依据用户确认的实况改为柜体内通道。柜面有白色横向木纹、深色浅绿花饰腰线和错层轨道，中央柜门沿轨道向左右滑开；关闭时封住通道，滑开后留出约一米净通行空间。此前示意模型中过道侧直接进入衣帽间的开口已封合，衣帽间通过主卧柜门进入。按 E 或点击门扇开关，平面图与游走碰撞跟随实际动画。游走底部「衣帽间柜门」和空间列表中的「衣帽间」都先到主卧柜门前，再手动走入。内部三面柜架、衣物与收纳为图纸基础上的估算重建，保留可走动空间。

## 项目结构

- `index.html`：可由 GitHub Pages 直接托管的完整内嵌页面。
- `index.source.html`：本地源码预览与离线构建使用的 HTML 模板。
- `validation/model-report.json`：按版本区分的检查记录。

- `src/data.js`：图纸坐标、墙、门窗、房间、家具清单和导览视点。
- `src/model.js`：程序化家具细节、建筑模型、材质与合并几何。
- `src/study.js`：依据书房实拍制作的家具、织物、柜体、学习用品与室内装饰。
- `src/bathroom.js`：依据卫生间实拍制作的瓷砖、弧形淋浴房、洗漱柜、实时镜面及挂墙生活用品。
- `src/master.js`：依据主卧实拍制作的软包床、窗帘、灯具、收纳细节及衣帽间推拉柜门。
- `src/artwork.js`：用户原照片的透视纹理映射与走廊挂画。
- `src/entry.js`：实拍入户门、凹凸门板、原照片贴纸与立体磁力片、电子门锁。
- `src/kitchen-dining.js`：实拍餐边柜与照片墙、厨房设施和小家电、两处玻璃推拉门。
- `src/plan.js`：同源 SVG 平面图和游走小地图。
- `src/app.js`：界面、相机、游走、碰撞、导览与导出。
- `public/drawings/`：用户提供的三张原图。
- `public/study/`：书房相框、挂历与书封所用的原始照片。
- `public/master/`：此前主卧细节采样所用的原始照片备份。
- `public/entry/`：入户大门所用的完整原始照片。
- `public/kitchen-dining/`：餐厅照片墙、推拉门学习挂图、地图和油烟机所用的完整原始照片。
- `vendor/`：Three.js 0.185.1；许可证见 `THREE-LICENSE.txt`。
