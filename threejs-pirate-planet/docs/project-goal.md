# 项目目标 — Three.js 微缩航海星球

## 1. 一句话目标

一个**可以旋转、缩放、定位、探索，并观察船只沿球面航线航行**的
**微缩航海星球**（马里奥银河式微缩世界 + 大航海 / 海盗主题）。

核心**不是**「普通 Three.js 贴图地球」，而是（§42）：

> 有建筑、有港口、有船只、有航线、有局部星球弧度、有右下角 Mini Globe 导航的微缩航海星球。

## 2. 视觉目标

| 必须做到 | 验收表现 |
|---|---|
| 真正的球体世界 | 禁止「平面地图 + 蓝色背景」；海洋 / 陆地 / 大气 / 云全为球面 |
| 明显星球曲率 | 局部视角下**地平线是弯曲的**，人站在球面感觉「在小星球表面」 |
| 微缩感 | 整个世界可一屏看全，像桌上摆件 |
| 卡通化 | Kenney 低多边形 + 渐变平涂，蓝绿海洋 + 阳光高光 |
| 建筑球面站立 | 北极建筑 ↑ / 赤道建筑 → / 南半球建筑 ↓，全部沿表面法线 |
| 船只球面航行 | 沿**大圆弧线**移动，船底朝球心、船头朝航线切线 |
| 大气与星空 | 星球边缘淡蓝色 Fresnel 光晕，星空不过亮不抢主体 |
| 昼夜 | 简单 `DirectionalLight + AmbientLight`，夜晚港口暖黄灯光 |

## 3. 操作方式

| 输入 | GLOBAL VIEW | LOCAL VIEW |
|---|---|---|
| 左键拖动 | 旋转观察地球 | 环视（绕局部视点） |
| 滚轮 | 缩放（改变相机轨道半径） | 拉近 / 推远贴地高度 |
| 点击船 | 选中 → 船只信息面板 | 同左 |
| 点击建筑 / 港口 | Hover 信息 + 选中 | 同左 |
| `🌍 全球 / 🔍 局部` 按钮 | 平滑飞行切换（禁止瞬移） | 同左 |
| 点击 Mini Globe | — | 取球面坐标 → 相机 FlyTo |
| 点击 Mini Globe 港口 Marker | — | 飞往该港口 |
| `Follow Ship` | — | 相机跟随船沿球面航行 |

## 4. MVP 范围（§36 — 只这些，不多做）

**包含**

```text
地球        Ocean Sphere + Land Mesh + Islands + Atmosphere + Clouds + StarField
港口        4~8 个（建筑 / 码头 / 木箱 / 木桶 / 树 / 岩石 / 旗帜）
船只        3~5 艘，各自不同航线，真实球面移动
视角        Global View + Local View + 平滑相机过渡
Mini Globe  右下角真 3D 小地球 + 港口 Marker + 当前位置 + 点击导航
交互        Hover 信息、船只选中面板、Follow Ship
光照        基础昼夜（Directional + Ambient，可转太阳方位）
性能        InstancedMesh 处理树 / 岩石 / 木箱 / 木桶
```

**明确不含（第一版）**：可玩战斗、火炮、水手、音效、任务系统、多人、移动端手势完整适配、
真实物理水体、屏幕后处理 Bloom、阴影贴图大面积投射。均记录在 `progress.md`。

## 5. 技术目标

```text
HTML5 + CSS3 + 原生 JavaScript ES Module + Three.js + Vite
允许增补：GSAP（相机飞行）、lil-gui（调试）、stats.js（FPS）
不引入 React/Vue 等大型框架
必须支持：npm install && npm run dev → 浏览器直接访问
```

## 6. 性能目标（§34）

| 指标 | 目标 | 依据 |
|---|---|---|
| 桌面帧率 | **60 FPS** | 实测全资产仅 ~27.8k tris |
| DrawCall | **< 120**（预算 ~70–80） | 见 `asset-audit.md` §6 |
| Instancing | 树 / 岩石 / 木箱 / 木桶各 1 DrawCall | 72 模型共享 1 张 512² 图集 |
| 加载 | 29 个 MVP 模型 ≈ 1.2 MB | 已拷贝至 `public/assets/pirate-kit/` |

## 7. 后续扩展方向（不做，仅方向）

LOD 分级（§35）、港口进入触发、航线贸易与货物、幽灵船夜晚事件、
Mini Globe 显示船只实时位置、多人海战、触屏完整适配、Bloom 与海面 SSAO。

## 8. 不可妥协的核心（永远优先）

```text
球形世界感 > 真实模型路径 > 建筑球面站立 > 船只球面航行
> 局部视角弯曲地平线 > Mini Globe 可导航 > 分阶段验收
```
