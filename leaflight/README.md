# 叶间微光 · Leaflight

在等角像素森林里，带着叶帽小精灵收集十二颗星露，躲过暗影菇，再返回树心祭坛点亮森林。

**[在线试玩](https://shfzhangjian.github.io/AI_GTA/leaflight/)** · [返回游戏合集](../) · [验证记录](./VALIDATION.md)

## 运行

直接双击本目录的 `index.html` 即可游玩，无需安装依赖或构建。保留 `sprites/` 文件夹及其他相对路径资源。

也可以用 Node.js 启动本地服务：

```bash
cd leaflight
node server.cjs
```

打开 <http://127.0.0.1:8786/>。可通过 `PORT` 环境变量更换端口；服务器只监听本机。本目录也可以直接由 GitHub Pages 等静态服务托管。

## 玩法

- WASD / 方向键移动；点击空地自动绕过树木和岩石寻路。
- 空格使用叶风冲刺，冷却 1.8 秒。冲刺期间无敌，撞到暗影菇还能让它眩晕 3 秒。
- 靠近星露自动拾取。集齐十二颗后，跟随金色引导线返回地图中央的树心祭坛获胜。
- 接触暗影菇会失去一格生命，三格生命耗尽后可以重新开始。
- P / Esc 暂停或继续；也可以使用页面上的按钮。声音默认关闭，右上角可以开启合成音效。
- 手机提供方向按钮与冲刺按钮，也可以点击地面寻路。

## 实现与素材

- 原生 HTML、CSS、JavaScript，Canvas 2D 绘制场景、粒子、树林和怪物，Web Audio 合成音效。
- `world.js`：地图、坐标投影、碰撞检测与网格寻路。
- `game.js`：游戏循环、输入、追逐、收集、冲刺、胜负状态、绘制与音效。
- `sprites/`：四斜向透明 PNG 与图集元数据；叶帽角色由内置 imagegen 生成，再通过 `scenario-iso-cycles` 的本地脚本整理。实际生成提示词见 [image-prompt.txt](./sprites/image-prompt.txt)。
- 角色使用四向静态图，运行时加入轻摆与位置起伏反馈；不包含模型生成的逐帧走路动画。
- 所有运行资源随目录提供，无外部库、字体或素材网络请求。
