# Tilt Lab · 倾斜实验室

使用 HTML、Three.js 和 Rapier 3D 制作的倾斜球台物理闯关游戏，支持电脑键盘与手机触摸摇杆。

## 玩法

倾斜球台，让小球依靠重力滚动。收集金色能量，绕过障碍，滚入绿色接球洞。小球真实下落到接球杯内后显示通关；收集全部能量不是通关的必要条件。

每关只有一种地面材质：

| 关卡 | 材质 | 特点 |
| --- | --- | --- |
| 01 木板入门 | 木板 | 均衡摩擦与滚动阻力 |
| 02 冰面弯道 | 冰面 | 低摩擦、惯性明显，需要提前反向倾斜减速 |
| 03 毛毡穿行 | 毛毡 | 高滚动阻力，适合精细控制 |

木纹、毛毡纤维和冰面气泡、裂纹由程序生成纹理。小球随机使用抛光黄铜、镜面铬、釉面陶瓷、珠光珐琅或铜材质；外观变化不改变球的质量。

## 操作

- 电脑：WASD / 方向键倾斜球台，R 重试。
- 手机或电脑：拖动右下角摇杆控制倾斜。
- 反向倾斜可减速；松开操作后球台回正，小球保留惯性。
- 顶部按钮支持更换小球外观、重试、暂停与继续；左侧可直接切换关卡。

## 本地开发

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci
npm run dev -- --port 5178
```

打开终端显示的地址。手机可在同一局域网访问开发服务器显示的 Network 地址。

## 构建和发布

```bash
npm run build
```

`dist/` 是自包含的静态构建，资源采用相对路径，可直接发布到 GitHub Pages 的子目录。运行时 Three.js 和 Rapier 已打包，字体通过 Google Fonts 加载，无法联网时使用系统字体。

[在线试玩](https://shfzhangjian.github.io/AI_GTA/tilt-ball/dist/)

不要直接以 `file://` 打开页面，应使用 HTTP 静态服务。例如在本目录运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/dist/`。

## 验证

```bash
node tools/verify-goal.mjs
```

物理检查验证小球能穿过洞口、落到接球杯底部，以及洞口边缘支持垂直接触。开发时还检查了桌面和手机竖屏布局、摇杆响应及关卡切换。

## 文件结构

- `src/main.js`：场景、关卡、固定步长物理、输入与通关状态。
- `src/materials.js`：程序纹理和小球材质。
- `src/goal.js`：接球洞几何、洞壁与杯底碰撞体。
- `src/style.css`：响应式界面。
- `tools/verify-goal.mjs`：接球洞物理验证。
- `dist/`：已构建的发布版本。

本项目由 Codex 协助开发。
