# 果冻西瓜验证记录

验证环境：Windows 上的 Chrome，通过 Playwright 驱动真实浏览器。渲染使用原生 WebGPU，读取实际 GPU 错误、物理节点、四面体体积、种子位置与动能；截图来自运行中的应用。

## 浏览器检查

39 项检查全部通过：

- 原生 WebGPU / WGSL 编译与多通道渲染，无 JavaScript 或 GPU 错误。
- 尖端、左右角、果肉、果皮均可抓取；拖动到画布外后，指针捕获保持抓取。
- 强拉伸后释放、连续轻推、地面碰撞、摩擦与稳定性；强拉伸释放后动能衰减，四面体保持正体积，未触发安全回退。
- 种子随变形表面移动；两面种子绑定检查通过。
- 硬度与阻尼滑块的 0、50、100 值，三组颜色预设，轻推、重置、网格显示、暂停 / 恢复。
- 暂停后节点位置保持完全一致；暂停时重置将动能清零。
- ¼速度使用相同固定步长，推进的模拟步数约为正常速度的四分之一。
- 双指同时抓取和扭转；390 px 宽手机布局控件位于画布下方，无横向溢出。
- 减少动态效果偏好下默认暂停；WebGPU 不可用时显示解释。
- 单文件从 `file://` 打开可运行；另使用 Chrome 默认启动参数验证离线 WebGPU 渲染。

最终浏览器拖拽样本的相对体积约为 99.60%–100.05%。该范围来自指定操作的采样，不能视为任意输入和设备上的误差保证。

## 物理静置检查

硬度设为 0、42、100，分别抓住尖端强拉伸，释放后推进 1,500 个固定模拟步（12.5 秒）：

| 硬度 | 静置相对体积 | 最小四面体相对体积 | 弹性边长度相对初始值的均方根误差 | 安全回退次数 |
| --- | --- | --- | --- | --- |
| 0 | 99.975% | 99.629% | 0.158% | 0 |
| 42 | 99.973% | 99.372% | 0.065% | 0 |
| 100 | 99.969% | 99.129% | 0.054% | 0 |

三组动能均降至 0.00002 mJ 以下，网格恢复稳定形状。软硬度为 0 时，抓取状态的弹性边长度均方根变化约为 8.5%，验证变形包含局部形变。

质量与动能使用应用标注的示意比例与密度进行换算；折射使用屏幕空间近似，气泡为材质光学细节。
