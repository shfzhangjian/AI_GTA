# 果冻西瓜 · Melon Jelly

可抓取、拉伸、弯曲、抬起和轻轻扭转的三维西瓜果冻。原生 WebGPU / WGSL 渲染，四面体 XPBD 体积软体模拟；果肉、浅色内皮与条纹绿皮具有不同的材质和硬度。

## 运行

`index.html` 是完整的独立应用，嵌入所有 JavaScript、CSS 与 WGSL，无需安装依赖或编译，也没有外部素材请求。可以直接用支持 WebGPU 且启用硬件加速的 Chrome 或 Edge 打开该文件。

也可从本目录启动静态服务：

```bash
python -m http.server 8768 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8768/>。远程托管需要 HTTPS；GitHub Pages 的 HTTPS 地址可直接运行。如果浏览器没有 WebGPU 或找不到可用 GPU，页面会明确说明原因。

## 操作

- 用鼠标或触屏抓住尖端、角落、果肉或果皮，拖动后释放，观察局部变形与回弹。双指抓取不同部位可扭转；抓取时滚动鼠标滚轮可调整深度。
- 三组西瓜配色预设；硬度、内部阻尼均可实时调整，滑块显示当前值。
- 「轻推一下」施加小幅扰动；「重置」恢复初始形状；「¼速度」放慢模拟；「显示网格」显示体积网格的弹性边。
- 「暂停实验 / 恢复实验」冻结或继续物理模拟。聚焦画布后，空格暂停 / 恢复，N 轻推，R 重置。
- 遵循系统的减少动态效果偏好：默认暂停，可手动恢复。

## 实现

455 个质量节点、1,728 个四面体，使用固定 1/120 秒步长、每帧最多 6 步与每步 10 轮约束求解。XPBD 弹性边、体积保持、防倒置约束、地面接触、摩擦和轻微反弹共同工作；果皮弹性边约为果肉的 2.8 倍硬度。两轮 Loop 细分曲面绑定物理节点，28 颗独立种子绑定两面的曲面三角形，随变形移动与旋转。

原生 WebGPU 多通道渲染：背面深度估算视线厚度，Beer–Lambert 光吸收、屏幕空间折射、菲涅尔反射、光泽高光、薄边透射与柔和阴影。细微气泡使用随材质坐标变形的光学细节。GPU 缓冲区、几何拓扑与着色器在拖动时复用。

实时读数来自模拟：相对体积以初始网格为 100%；质量与动能按 1 场景单位 ≈ 6.5 cm、密度 720 kg/m³ 换算，属于示意比例下的近似值。

桌面、手机布局与触控等 39 项浏览器检查通过；另测试了三种硬度下的强拉伸、释放与长期静置。详见 [验证记录](./VALIDATION.md)。不同设备的 WebGPU 支持与性能取决于浏览器和显卡。
