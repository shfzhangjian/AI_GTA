# 简体中文界面更新

此更新保留同一个网站、原有私密访问设置、游戏操作和接口结构。

已汉化：
- 页面标题、主菜单、暂停菜单、设置、分享与嵌入
- 十种武器名称、操作说明、触控按钮与无障碍标签
- 房间创建和加入、昵称、邀请、房主提示、排行榜、生命值、击败计数、重生与胜负结算
- 加载状态、截图隐私说明、免费额度/超时提示、网址验证与服务端错误
- 内置演示网页和维基百科示例中的画布文字

保留：Pixel Lab、Sprite Fusion、服务商及素材作者名称、原始许可证、网址和实际按键标识。玩家自行输入的昵称与任意外部网页截图内容不会被自动翻译。

中文显示使用苹方、微软雅黑、Noto Sans CJK SC 等字体回退。界面字号和换行已针对中文调整。

检查结果：
- TypeScript 检查通过
- 中文画布渲染通过，字符清晰、无缺字
- 十种武器、手雷与移动/跳跃/飞行/翻转的引擎回归检查通过
- 静态字符串清单检查覆盖 249 个中文文案条目；剩余拉丁文字为品牌、网址、按键、素材名与许可证
- 实际浏览器试玩、触屏交互和联网对战仍需完成待处理的登录。平台静态预览图仅用于布局检查，不作为完整交互验收
