# 3D 台球 · Three.js

真实比例的台球游戏：球直径 63.5mm（R = 0.03175m），台面 2.375m × 1.155m，袋口直径约 2.5 倍球径。
单文件渲染 + 纯物理 + WebAudio 程序化音效，零音频素材、零构建步骤。

## 玩法

- **鼠标移动**：瞄准（虚线 + 幽灵球预测落点）
- **按住左键**：来回摆动的蓄力条（绿→黄→红）
- **松开**：击球
- **R**：母球摔袋后重新摆回开球点
- **0**：恢复 15 球三角摆位
- **你 vs 电脑**回合制：击落目标球 +1 分并继续击球；母球摔袋 −1 分交换球权；清空 15 颗目标球者获胜

## 技术

| 模块 | 说明 |
| --- | --- |
| `main.js` | Three.js r165 场景（台球桌/球杆/吊灯/阴影）+ 平面物理（480Hz 子步、球-球弹性碰撞、库边反弹、袋口吸引）+ 回合制状态机 + 几何 AI（母球→目标球→袋口假想接触点求解 + 路径遮挡检测） |
| `sound.js` | 全程序化 WebAudio：球碰撞"嗒"、库边闷响、击球、落袋（下滑+咚+沙沙）、犯规警示、环境嗡嗡、胜利和弦；物理子步内只记录碰撞、渲染帧批量合成，杜绝爆音 |
| `serve.js` | 本地预览静态服务器（ES Module 需 http 环境） |
| `smoke.js` | headless Chrome CDP 冒烟测试：摆位体检（minPair == 2R）、开球物理推演、球杆几何诊断（杆尖与期望位置误差 0mm） |
| `index.html` | 界面：记分板、蓄力条、已入袋托盘、状态提示 |

## 运行

```bash
node serve.js          # http://127.0.0.1:8765
# 或任意静态服务器
python -m http.server 8765
```

## 调试 API

页面暴露 `window.__DBG`：`shoot(angle, power)` / `state()` / `audit()` / `physicsStep(dt)`（供自动化测试直连物理）。
