# 一笔，如何成为一个数字

一个全屏 SVG + Three.js + HTML 科普动画。画面是一条连续时间线，讲解文字、公式、手写轨迹与三维特征层同步变化。

## 播放

- [在线动画](https://shfzhangjian.github.io/AI_GTA/digit-recognition/) · [离线单文件版](https://shfzhangjian.github.io/AI_GTA/digit-recognition/digit-recognition.html)
- 打开 `digit-recognition.html` 即可离线播放。Three.js 已内嵌，不需要联网。
- 或运行 `node server.cjs`，访问 http://127.0.0.1:4180/ 。
- 顶部可切换手写数字 1、2、3、4、5、6、7、8、9、0。
- 底部可播放/暂停、前后分步、拖动进度、调速、全屏。
- 空格控制播放，左右方向键切换步骤；输入控件获得焦点时保留原生键盘操作。
- 初次打开自动播放一次，结束后停止。系统启用“减少动态效果”时默认暂停。

## 77 秒时间线

| 时间 | 场景 | 画面 |
| --- | --- | --- |
| 0–7 秒 | 手写输入 | SVG 按轨迹绘制数字 |
| 7–16 秒 | 居中与采样 | 笔迹等比居中，变成 14×14 灰度矩阵 |
| 16–24 秒 | 二值化 | 阈值逐格扫描，出现 0、1 |
| 24–38 秒 | 卷积 | 3×3 窗口移动，显示权重和实际乘加结果 |
| 38–47 秒 | 特征分层 | Three.js 将输入和两张响应图展开为三维层 |
| 47–57 秒 | 最大池化 | 2×2 响应压缩为一个最大值 |
| 57–68 秒 | 模板比较 | 72 个特征与十个手写模板逐一比较 |
| 68–77 秒 | 分类结果 | 手写答案重新显现，展示十类相对分数 |

## 数学与模型

所有数值来自 `handwriting-model.js` 中的实际计算：笔迹居中 → 14×14 覆盖率采样 → 阈值 0.20 → 两个固定 3×3 滤波器 → 绝对值响应 → 2×2 最大池化 → 72 维特征 → 模板平方距离 → 温度为 12 的 Softmax。

两个滤波器分别为 `[[1,1,1],[0,0,0],[-1,-1,-1]]` 和 `[[1,0,-1],[1,0,-1],[1,0,-1]]`。每格采样 25 个点；卷积窗口步幅 1、无补边；池化步幅 2。三维位置是展示方式，不会改变计算值。

这是每类一个固定手写模板的教学模型，没有训练过程。相对分数不等于实际准确率，也不用于通用 OCR。

## 文件与构建

- `index.html` / `film.css`：全屏动画舞台和播放控制。
- `film.js`：Three.js 三维对象、SVG 轨迹、时间线与同步讲解。
- `handwriting-model.js`：手写轨迹和全部数学运算。
- `vendor/three.cjs`：本地 Three.js 0.185.1，MIT 许可见 `vendor/THREE-LICENSE.txt`。
- `build.cjs`：构建浏览器版本和离线 HTML。运行 `node build.cjs`。
- `verify.cjs`：验证十个数字、八章、播放控制、六种窗口尺寸、离线运行和减少动态效果设置。通过 `PLAYWRIGHT_PATH` 可指定本机 Playwright。

浏览器验证需要 Playwright 与 Microsoft Edge。先运行本地服务，再执行 `node verify.cjs`；可用 `BASE_URL` 指定其他预览地址。

Three.js 来自本机已有依赖，运行不访问 CDN。浏览器需要支持 WebGL 2。
